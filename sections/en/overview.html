Patient Registration Overview

The Patient Registration module is a comprehensive, FHIR-compliant system for registering new patients and creating visit records. It combines patient search, form-based data entry, and visit management in a single, responsive interface that adapts to desktop, tablet, and mobile devices.

Key Features

The patient registration system provides comprehensive capabilities for managing patient records and visit creation:

Search and Lookup

  • Unified Patient Search - Search by personal ID, name, or registration number with keyboard shortcut (Cmd/Ctrl+K)
  • Advanced Filters - Filter by birthdate, phone, address, and other criteria
  • Dual-Action Results - Each result offers "New Visit" (create encounter) or "Fill Form" (populate form fields) actions
  • Auto-Search - Personal ID field automatically triggers search when 11 digits are entered
  • Duplicate Detection - Warns when creating patients with similar names or Personal IDs

Patient Registration

  • Personal ID Validation - Georgian 11-digit Personal ID with Luhn checksum verification
  • Unknown Patient Mode - Emergency registration for patients without identification (generates temporary ID)
  • Guardian Support - Automatic guardian fields for minors (<18 years old) with RelatedPerson FHIR resource
  • International Phone - Phone number input with country code selector
  • Address Management - Region/district/city cascading selectors with Georgian administrative divisions

Visit Management

  • Create Visit Toggle - Enable/disable visit creation; when ON, shows 4 additional sections (Registration, Insurance, Guarantee, Demographics)
  • Visit Types - Outpatient, Inpatient, Emergency, with department filtering based on selection
  • Active Visit Warning - Detects existing active encounters and warns before creating duplicate visits
  • Registration Numbers - Auto-generated sequential registration numbers per encounter
  • Today's Visits Sidebar - Real-time list of today's encounters with status badges and time stamps

Insurance and Guarantees

  • Multi-Insurer Support - Add up to 3 insurance companies per patient with Coverage FHIR resources
  • Insurance Enable Toggle - Conditionally show/hide insurance fields
  • Copay Configuration - Set copay percentages, policy numbers, issue dates, and validity periods
  • Virtual Advance - Guarantee/deposit system with amount, donor, and deadline tracking
  • Document Attachments - Upload guarantee letters and supporting documents

Form Experience

  • Collapsible Sections - 9 accordion sections expand/collapse independently to reduce visual clutter
  • Progress Indicator - Visual tracker showing completion status of each section
  • Draft Auto-Save - Form data saved to localStorage every 1 second, with "Draft Saved" badge indicator
  • Draft Recovery - Restore unsaved form data after browser reload or crash
  • Sticky Submit Button - Submit button fixed at bottom on mobile for easy access
  • Responsive Wizard - Mobile displays 5-step wizard (Patient → Personal Info → Contact → Registration → Insurance) instead of accordion

Data Standards

  • FHIR R4 Compliance - All data stored as FHIR resources (Patient, Encounter, Coverage, RelatedPerson, Organization)
  • GoodKey Data Binding - 101+ code mappings for Georgian healthcare standards
  • Multi-Language - Full support for Georgian, English, and Russian with real-time language switching
  • Accessibility - Keyboard navigation, screen reader support, and WCAG 2.1 AA compliance
Recent Patients Filtering: The Recent Patients sidebar automatically excludes portal patients (patient portal registrations) and only shows EMR-registered patients, limited to the 10 most recently updated records.
