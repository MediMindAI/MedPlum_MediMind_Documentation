Warehouse Dashboard

The Warehouse Dashboard is the operational command center for your hospital's supply chain. It brings together real-time stock metrics, critical alerts, pending approvals, and activity logs into a single view -- giving warehouse staff an immediate picture of what needs attention right now.

The dashboard fetches data once when the page loads. To update the numbers, click the refresh button in the header. A 60-second cache prevents redundant API calls when refreshing rapidly.

FHIR Data Sources: KPI cards pull data from multiple FHIR resources -- Basic (StockQuant) for stock levels, SupplyDelivery for receipts and transfers, and SupplyRequest for pending orders. All data is cached for 60 seconds to balance freshness with performance.

Critical Alerts Banner

When stock-outs or expired items are detected, a colored alert banner appears directly below the KPI cards. This banner acts as an urgent visual warning that cannot be missed:

  • Red banner -- appears when any item has zero stock (stock-out). Shows the count of affected items
  • Orange banner -- appears when items have passed their expiry date. Shows the count of expired items
  • Combined banner -- if both stock-outs and expired items exist, both counts appear in the same banner

Click "View Details" on the banner to navigate directly to the inventory balances page, filtered to show the problem items.

Immediate Action Required: Stock-out alerts (red banner) mean departments cannot receive supplies they may need for patient care. These should always be addressed first -- either by creating an emergency order or redirecting stock from another location.

1.2 Quick Actions

Below the alerts, four quick action cards provide one-click access to the most common warehouse operations. Each card shows an icon, a label, and a brief description of what it does.

Action Card Description Navigates To
New Receipt Record incoming goods Receptions page (create new receipt)
New Transfer Move between departments Transfers page (create new transfer)
Confirm Orders Review pending orders. Shows a badge with the number of pending orders when orders are waiting Order Confirmation page
View Balances Current stock levels Inventory Balances page
Pending Order Badge: The "Confirm Orders" card displays a small blue number badge when there are pending department requests. This makes it easy to see at a glance whether orders are waiting for your attention.

Pending Approvals

The Pending Approvals panel appears in the Intelligence section and lists the most recent transfer requests awaiting confirmation. Each entry shows:

  • Item name and quantity with unit of measurement
  • Transfer route -- which department is sending and which is receiving (e.g., "Central Warehouse -> Surgery")
  • Date when the transfer was requested

If more pending transfers exist than can be shown, a "View All" link at the bottom navigates to the full transfer confirmation page.

Expiry Countdown

Next to the Pending Approvals, the Expiry Countdown panel lists the top 5 items closest to their expiry date. Each item is color-coded based on urgency:

Color Timeframe Recommended Action
Red 7 days or less Use immediately or transfer to a department that needs it
Orange 8 to 30 days Prioritize for upcoming use; consider inter-department transfer
Blue More than 30 days Monitor -- no immediate action needed

Each entry includes the item name, lot number, and a badge showing the number of days remaining.

1.3 Notifications Feed

The Notifications Feed provides a real-time stream of warehouse events. Unlike the Recent Activity timeline (which shows completed actions), the notification feed tracks system-generated alerts from FHIR Communication resources -- things like new receipts being created, transfers being completed, or procurement status changes.

Notification Types

Each notification is categorized by type and displayed with a matching icon and color accent:

Type Description Example
Receipt New supply deliveries received "Receipt created: Amoxicillin 500mg x 500"
Transfer Inter-department supply movements "Transfer initiated: Central Warehouse -> Surgery"
Transfer Completed Transfers that have been fully received "Transfer completed: 200 gloves delivered to Surgery"
Procurement New purchase order submissions "Procurement request: Medical Supplies Q1"
Procurement Status Status changes on existing procurement requests "Procurement PO-2024-003: Approved"
Write-Off Items removed from inventory (damaged, expired, etc.) "Write-off confirmed: 25 expired Nitroglycerin tablets"

Unread Indicators and Actions

  • Unread dot -- a small blue indicator appears on notifications you have not yet viewed
  • Unread count badge -- the header shows how many unread notifications are pending
  • Mark All Read -- click this button to clear all unread indicators at once
  • Click to navigate -- clicking any notification marks it as read and navigates to the related page (e.g., clicking a receipt notification opens that receipt)
  • Priority badges -- urgent or high-priority notifications display a colored badge to draw extra attention
FHIR Communication Resources: Notifications are stored as FHIR Communication resources with warehouse-specific extensions. The system supports i18n-encoded text, so notification messages automatically appear in the user's selected language.

Recent Activity Timeline

The Recent Activity section displays a chronological feed of the latest warehouse operations. Unlike notifications (which are system-generated alerts), this timeline shows completed user actions -- receipts processed, transfers made, adjustments recorded, and more.

Each activity entry shows:

  • Event icon -- color-coded by type (green for receipts, blue for transfers, orange for adjustments, red for expiry events)
  • Title -- a brief description of the action taken
  • Details -- additional context such as supplier name, item quantities, or lot numbers
  • Relative time -- how long ago the event occurred (e.g., "30 minutes ago", "3 hours ago")
  • Performed by -- the staff member who carried out the action
Activity Type Color Description
Receipt Green Items received from a supplier into the warehouse
Transfer Blue Items moved between departments or warehouse locations
Request Cyan A department submitted a supply request
Adjustment Orange Manual stock corrections (inventory count, damage, loss)
Expiry Alert Red Items flagged as expired and removed from usable stock

The timeline displays up to 20 recent entries and supports click-to-navigate -- clicking an activity item opens the related record (e.g., clicking a receipt entry opens that receipt's detail page).

Currently Active Types: The dashboard currently generates Receipt and Transfer activity entries from the last 7 days. The Request, Adjustment, and Expiry Alert types are supported by the display component but are not yet produced by the data source.

1.4 Analytics Overview

The bottom section of the dashboard provides a quick analytics snapshot with two side-by-side panels: a Daily Volume Chart and the Top Moved Items ranking.

Daily Volume Chart

This chart shows 30-day sparklines for two key metrics:

  • Receipts (green line) -- daily count of incoming deliveries over the past 30 days, with a running total
  • Transfers (blue line) -- daily count of inter-department transfers over the past 30 days, with a running total

The sparklines use SVG area fills for visual impact, making it easy to spot trends, seasonal patterns, and unusual spikes. Weekends and holidays often show zero activity (flat portions of the chart).

Top Moved Items

This panel ranks the top 5 most-moved items by total quantity distributed. Each item shows:

  • Rank badge -- numbered 1 through 5, with the top two highlighted for visual emphasis
  • Item name -- the product name from the warehouse nomenclature
  • Quantity -- the total number of units moved
  • Progress bar -- a gradient bar showing relative volume compared to the highest-moving item

This ranking helps identify which supplies are in highest demand, useful for planning reorder quantities and negotiating supplier contracts.

Analytics vs. Full Reports: The dashboard analytics are a quick visual summary. For detailed analysis -- including ABC/XYZ classification, dead stock detection, expiry risk assessment, and budget planning -- navigate to the Analytics module using the main navigation menu.
