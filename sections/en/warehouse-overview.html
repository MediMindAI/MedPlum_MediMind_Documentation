Warehouse Dashboard

The Warehouse Dashboard is the central monitoring hub for all warehouse operations. It provides a real-time overview of stock health, pending tasks, and recent activity -- giving warehouse managers a single screen to assess operational status and take immediate action.

Dashboard Layout

The dashboard is organized into six visual sections, stacked vertically. Each section appears conditionally -- if there is no data to show (e.g., no critical alerts, no pending transfers), that section is hidden automatically to keep the view clean.

7 Dashboard Sections
6 KPI Metrics
4 Quick Actions
60s Auto-Refresh

The seven sections, from top to bottom:

Section Purpose Visibility
Critical Alerts Banner Red/orange banner warning about stock-outs or expired items Only when stock-outs or expired items exist
KPI Summary Strip Six key metrics displayed as cards with icons and sparkline trends Always visible
Quick Actions Four navigation cards for common warehouse tasks Always visible
Intelligence Grid Pending transfer approvals table and expiry countdown timers When pending transfers or expiring items exist
Analytics Grid 30-day volume sparklines and top moved items ranking When receipt or transfer data exists
Recent Activity Timeline of warehouse events from the last 7 days Always visible (shows empty state message if no events)
Notifications Real-time notification feed for transfers, procurement, and system events Always visible
Auto-Refresh: The dashboard automatically refreshes all data every 60 seconds. A "last updated" timestamp appears in the page subtitle (e.g., "Updated 2 min ago"). You can also manually refresh by clicking the retry button if an error occurs.

KPI Metrics

The KPI summary strip displays six operational metrics as color-coded cards. Each card shows an icon, a numeric value, and a label. The last two metrics (Receipts Today and Transfers Today) also include mini sparkline charts showing the 30-day trend.

Metric Color Description FHIR Source
Pending Transfers Amber (warning) Count of transfer requests with status "in-progress" awaiting confirmation SupplyDelivery (status: in-progress)
Stock-Outs Red (error) Items with zero stock quantity -- requires immediate attention InventoryReport balance where quantity = 0
Low Stock Items Amber (warning) Items below 50% of their minimum reorder point (default threshold: 10 units) InventoryReport balance vs. minimum quantity
Expiring in 30 Days Blue (info) Items whose expiry date falls within the next 30 days InventoryReport item expiry date
Receipts Today Green (success) Number of goods receipts processed today, with a 30-day sparkline trend SupplyDelivery (type: receipt, date: today)
Transfers Today Blue (primary) Number of inter-department transfers processed today, with a 30-day sparkline SupplyDelivery (type: transfer, date: today)

Alert Thresholds

The system uses configurable thresholds to classify alerts by severity. These thresholds determine when an item triggers a warning versus a critical alert:

Alert Type Severity Threshold
Stock-Out Critical Quantity = 0
Expired Critical Expiry date has passed
Expiring Soon (critical) Critical Within 7 days of expiry
Expiring Soon (warning) Warning Within 30 days of expiry
Expiring Soon (info) Info Within 60 days of expiry
Low Stock Warning Below 50% of minimum reorder point
Critical Alerts Banner: When stock-outs or expired items are detected, a colored banner appears at the top of the dashboard. A red border indicates stock-outs; an orange border indicates expired items. Clicking "View Details" navigates to the inventory page with a stock view filter.

Quick Actions

The Quick Actions section provides four command cards for the most common warehouse tasks. Each card is a clickable button that navigates directly to the relevant page, saving time on multi-step navigation.

Action Description Navigates To
New Receipt Record incoming goods from a supplier Receptions page
New Transfer Create an inter-department stock transfer Transfers page
Confirm Orders Review and approve pending order requests (shows count badge when orders are pending) Order Confirmation page
View Balances Check current stock levels across all warehouses and departments Balances page

Analytics and Activity

The bottom half of the dashboard is divided into two analytical sections: the Intelligence Grid (pending approvals + expiry countdown) and the Analytics Grid (volume trends + top items). Below both grids sits the Recent Activity timeline.

Pending Approvals

A compact table showing the top 5 pending transfer requests awaiting confirmation. Each row displays:

  • Date -- when the transfer was requested
  • Route -- source department to destination department (e.g., "Main Warehouse to Pharmacy")
  • Item -- the item name being transferred
  • Quantity -- the amount and unit of measure

If more than 5 transfers are pending, a "View all (N)" link appears at the bottom, navigating to the full transfer confirmation page.

Expiry Countdown

Displays the 5 soonest-expiring items with color-coded countdown badges:

  • Red badge -- 7 days or fewer until expiry
  • Orange badge -- 8 to 30 days until expiry
  • Blue badge -- 31 to 60 days until expiry

Each item shows the product name and lot number (if available) for quick identification.

Daily Volume Chart

Two SVG sparkline charts showing the 30-day trend for:

  • Receipts (green line) -- daily count of goods received, with the 30-day total displayed
  • Transfers (blue line) -- daily count of inter-department transfers, with the 30-day total displayed

The sparklines use area fills beneath the trend lines for clear visual impact. If neither receipts nor transfers have any data, this section is hidden.

Top Moved Items

A ranked list of the 5 most frequently moved items over the past 30 days, combining both receipt and transfer volumes. Each item shows:

  • A rank badge (gold for 1st, silver for 2nd, default for 3rd-5th)
  • The item name and total quantity moved
  • A gradient progress bar showing volume relative to the top item

Recent Activity Timeline

A vertical timeline displaying the last 20 warehouse events from the past 7 days. Each event includes an icon, title, description, timestamp, and type badge. Events are color-coded by type:

Event Type Color Description
Receipt Green Goods received from a supplier, showing supplier name, item, and quantity
Transfer Blue Stock moved between departments, showing source and destination
Request Cyan Stock request submitted by a department
Adjustment Orange Manual stock correction or reconciliation
Expiry Red Item expiry alert triggered

Timestamps display as relative time (e.g., "3 min ago", "2 hours ago", "5 days ago") and fall back to a formatted date for events older than 7 days. Clicking on an activity item navigates to the relevant page (receipts or transfers).

Notifications

The Notifications section provides a real-time feed of system events related to warehouse operations. Each notification appears as a card with an icon, title, description, and timestamp -- keeping warehouse staff informed without leaving the dashboard.

Each notification card displays:

  • Icon -- Color-coded icon indicating the notification type
  • Title -- Brief summary of the event
  • Description -- Additional details about the event
  • Timestamp -- Relative time since the event occurred

A "Mark all as read" button with an unread count badge appears at the top of the feed, allowing users to clear all unread notifications at once.

Notification Type Priority Description
Transfer High Incoming transfer requests, approvals, and rejections
Procurement Medium Procurement status changes (submitted, approved, ordered, received)
Stock Alert High Stock-out warnings and low stock threshold notifications
Expiry Medium Items approaching or past their expiration date
System Low General system events (imports completed, reports generated)
Data Sources: The dashboard aggregates data from FHIR SupplyDelivery resources (for receipts and transfers) and InventoryReport resources (for stock balances and expiry tracking). All calculations happen in real-time using the Medplum FHIR API, with a 60-second client-side cache to reduce redundant API calls.
