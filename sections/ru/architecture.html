FHIR-ресурсы

Модуль регистрации создает и управляет следующими FHIR R4 ресурсами:

Ресурс Назначение Создается когда
Patient Основная демографическая запись пациента При каждой регистрации
Encounter Запись о визите / посещении Когда «Создать визит» ВКЛ
Coverage Данные страхового покрытия При добавлении страхования
RelatedPerson Информация об опекуне / представителе При вводе данных опекуна
DocumentReference Загруженные гарантийные документы При прикреплении файлов

Поток создания FHIR-ресурсов

При отправке регистрации создаются следующие FHIR-ресурсы:

sequenceDiagram participant U as User participant F as Form participant S as Service participant M as Medplum U->>F: Submit Registration F->>S: createPatient() S->>M: POST /Patient M-->>S: Patient ID F->>S: createEncounter() S->>M: POST /Encounter M-->>S: Encounter ID F->>S: createCoverage() S->>M: POST /Coverage M-->>S: Coverage ID S-->>F: Success F-->>U: Registration Complete
