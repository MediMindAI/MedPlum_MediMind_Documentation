1

Управление расходными материалами отделения

Модуль «Управление расходными материалами отделения» (также известный как «Расход пациента» или «Стационар») -- это основное рабочее место медсестры для учета каждого расходного материала и процедуры, использованных стационарными пациентами. Представьте его как подробный журнал, в котором фиксируется каждый бинт, шприц, медикамент и медицинская процедура по каждому конкретному пациенту -- чтобы больница точно знала, что было использовано, когда и для кого.

Интерфейс разработан с акцентом на скорость и точность. Палатные медсестры обычно работают в условиях дефицита времени, поэтому макет размещает наиболее часто используемые элементы управления -- выбор пациента, поиск по складу и ввод расхода -- в пределах быстрой доступности, без навигации по страницам или модальных окон для повседневных задач.

Используемые FHIR-ресурсы: Данные о расходе пациента хранятся с использованием ChargeItem (каждое использование расходного материала или процедуры), Basic/StockQuant (уровни запасов отделения), Encounter (госпитализация пациента), Location (назначение палаты) и ActivityDefinition (шаблоны процедур с предопределенными списками расходных материалов).

1.1 Макет страницы и навигация

Страница разделена на пять различных областей, каждая из которых выполняет определенную роль в процессе учета расхода. Макет повторяет традиционную рабочую станцию больничного отделения -- фильтры слева, пациенты в центре, склад справа и область ввода/истории внизу.

Заголовок

Иконка больницы + название страницы + регистрационный номер и имя выбранного пациента

Слева: Фильтры

Отделение, Дата, Ползунки времени

Центр: Список пациентов

Пациенты + История переводов

Справа: Панель склада

Действия, Поиск, Инвентарь

Внизу слева: Ввод расхода

Переключатель режима, поиск, список истории

Внизу справа: Детали события

Подпозиции процедуры, цены, итоги

Строка статуса

Пульсирующая зеленая точка + индикатор «Онлайн (N пациентов)»

Заголовок

Заголовок занимает всю ширину страницы с градиентным фоном. Он показывает иконку больницы и название страницы. Когда пациент выбран из центрального списка, его регистрационный номер и полное имя отображаются в заголовке, напоминая медсестре, с каким пациентом она работает.

Строка статуса

В самом низу страницы тонкая строка статуса показывает пульсирующую зеленую точку и текст «Онлайн (N)», где N -- количество пациентов, загруженных в список. Это подтверждает, что соединение активно и данные актуальны.

Типичный рабочий процесс

  1. Выберите отделение из фильтра в левой боковой панели (по умолчанию -- Приемное)
  2. Нажмите на пациента в центральном списке для его выбора
  3. Внизу слева найдите расходный материал или процедуру
  4. Укажите количество и нажмите кнопку «Добавить» (или нажмите Enter)
  5. Позиция появляется в истории расхода; остаток на складе автоматически уменьшается

1.2 Боковая панель фильтров (левая колонка)

Левая боковая панель (фиксированная ширина 260px) содержит три элемента управления фильтрами, определяющих, каких пациентов и какой склад вы видите. Она имеет характерную левую границу акцентного синего цвета для быстрой визуальной идентификации.

Элемент управления Что делает Детали
Выпадающий список отделений Фильтрует, какие пациенты отображаются в центральном списке С поиском, с возможностью очистки. Автоматически выбирает отделение «Приемное» при первой загрузке (поиск по ключевому слову на грузинском, английском или русском)
Выбор даты Устанавливает дату «по состоянию на» для просмотра поступлений пациентов Встроенный виджет календаря. По умолчанию -- сегодняшняя дата. Изменение даты перезагружает список пациентов и показывает, кто был госпитализирован на эту дату или ранее
Отображение времени + Ползунки Точная настройка времени для метки «по состоянию на» Показывает текущее выбранное время в формате ЧЧ:ММ. Ползунок часов от 0 до 23; ползунок минут от 0 до 59. По умолчанию -- 23:59 (конец дня)
Задержка при перетаскивании ползунка: Перетаскивание ползунка времени не вызывает API-запрос при каждом пикселе движения. Система ждет 500 миллисекунд после прекращения перетаскивания, прежде чем обновить список пациентов -- это предотвращает излишнюю нагрузку на сервер, сохраняя при этом отзывчивость интерфейса.

Синхронизация отделений

При изменении фильтра отделения происходят два действия одновременно:

  • Список пациентов обновляется и показывает пациентов, госпитализированных в выбранное отделение
  • Панель склада (правая колонка) автоматически переключается на показ инвентаря того же отделения

Эта синхронизация работает благодаря тому, что палаты (FHIR-ресурсы Location) и складские отделения (FHIR-ресурсы Organization) сопоставляются по наименованию. Выбор «Приемное» в фильтре пациентов автоматически выбирает «Приемное» в выпадающем списке складского отделения.

1.3 Список пациентов (центральная колонка)

Центральная колонка показывает всех пациентов, находящихся в выбранном отделении. Она состоит из двух частей: основная таблица пациентов и, при выборе пациента, мини-таблица истории переводов ниже.

Таблица пациентов

Таблица содержит три столбца:

Столбец Содержание Детали
# (Индикатор) Порядковый номер строки Отображается в виде круглого нумерованного индикатора. Индикатор выбранного пациента меняет стиль на выделенный
ФИО пациента Полное имя пациента Занимает 55% ширины таблицы
Личный номер 11-значный грузинский личный номер Занимает 30% ширины таблицы

Нажмите на строку пациента для его выбора. Строка выделяется цветом, а имя пациента появляется в заголовке выше. Нажмите на ту же строку снова для отмены выбора. Одновременно можно выбрать только одного пациента.

В заголовке панели отображается индикатор количества пациентов (напр., «12»), отражающий, сколько пациентов в текущем отфильтрованном списке. Если ни один пациент не соответствует фильтру, вместо таблицы отображается пустое состояние с иконкой и сообщением.

История переводов

При выборе пациента под списком пациентов появляется вторичная таблица, показывающая историю переводов между отделениями -- каждое отделение, куда пациент был переведен в ходе текущей госпитализации. Это полезно для отслеживания пациента, который перемещался между отделениями (напр., из Приемного в Хирургию, затем в Реабилитацию).

Столбец Содержание
# Порядковый номер перевода
Отделение Название палаты или отделения
Дата Дата перевода
FHIR-маппинг: Данные списка пациентов получаются из ресурсов Encounter со статусом «in-progress» или «finished», отфильтрованных по ID Location палаты. История переводов формируется из записей истории размещения ресурса Encounter.

1.4 Панель склада (правая колонка)

Правая колонка -- это вид инвентаря отделения. Она показывает, какие расходные материалы доступны в выбранном отделении, и предоставляет кнопки быстрого доступа к отчетам и расчетам. Имеет левую границу основного темно-синего цвета.

Выпадающий список отделений

Вверху расположен выпадающий список для выбора отделения, чей склад вы хотите просмотреть. Он независим от фильтра пациентов слева -- вы можете просматривать пациентов одного отделения, проверяя склад другого, хотя обычно они синхронизированы.

Строка кнопок действий

Под выпадающим списком отделений расположена строка кнопок действий для быстрого доступа к модальным окнам и отчетам:

Кнопка Подпись Что открывает Нужен пациент?
Иконка калькулятора Расчет Полное модальное окно расчета стоимости (3 вкладки) для выбранного пациента Да
Кнопка «H» История отделений Модальное окно со всеми пациентами, сгруппированными по отделениям с датами госпитализации Нет
Кнопка «O» Снабжение отделения Модальное окно с историей поставок расходных материалов для текущего отделения Нет
Дневной баланс Дневной баланс Модальное окно с таблицей дневного расхода и кнопками печати Нет
Измерение Лечение/Исследования Модальное окно с двумя вкладками (Расходные материалы, Исследования), показывающее сводку расхода пациента Да
Иконка обновления Обновить склад Перезагружает список складских позиций с сервера Нет

Поиск по складу и список позиций

Под кнопками действий расположена строка поиска с кнопкой обновления, позволяющая фильтровать складские позиции по наименованию или коду. Поиск фильтрует список в реальном времени по мере ввода.

Таблица склада содержит три столбца:

  • Наименование -- отображаемое название, включающее штрихкод, название продукта, поставщика, номер партии и срок годности (формат: *штрихкод* наименование *поставщик* партия (срок годности))
  • Количество -- отображается в виде индикатора. Когда количество падает до 5 или менее, индикатор становится красным, предупреждая медсестру о низком остатке
  • Ед. изм. -- единица измерения (напр., «шт.», «уп.», «мл»)

Нажмите на складскую позицию для её выбора и добавления в расход пациента. Строка позиции выделяется, и её название автоматически заполняется в поле поиска в области ввода расхода внизу слева.

Предупреждение о низком остатке: Когда индикатор количества складской позиции становится красным (5 или менее единиц), рассмотрите возможность уведомления склада для организации трансфера или пополнения. Нехватка расходных материалов в середине смены может повлиять на качество медицинской помощи.

1.5 Ввод и история расхода (нижняя зона)

Нижняя зона разделена на две колонки и является местом фактического учета расхода материалов. Левая сторона предназначена для добавления и просмотра расходов, правая показывает детали выбранной процедуры.

Внизу слева: Ввод расхода

Полоса заголовка содержит три элемента: выпадающий список выбора режима, иконку и текущую дату. Ниже -- строка поиска с тремя элементами управления для ввода позиций:

Элемент управления Назначение Поведение
Поле поиска Поиск позиций или процедур для добавления Показывает выпадающий список автозаполнения с подходящими результатами. В режиме «Расход» показывает складские позиции с количеством и единицей измерения. В режиме «Процедура» показывает процедуры с кодом услуги, названием и ценой в GEL
Поле количества Указать количество единиц для записи Числовое поле с минимумом 1. Сбрасывается до 1 после каждого ввода
Кнопка добавления (+) Отправить запись о расходе Неактивна, пока не выбраны и пациент, и позиция/процедура. Показывает индикатор загрузки во время отправки. Также можно нажать Enter в поле поиска или количества для отправки

Два режима ввода

Выпадающий список переключателя режимов переключает между двумя типами ввода расхода:

Режим Что записывает Влияние на склад Автозаполнение показывает
Расход Физические расходные материалы, использованные на пациенте (бинты, шприцы, медикаменты) Уменьшает остаток отделения на введенное количество Складские позиции с: отображаемым названием, доступным количеством и единицей измерения (напр., «Марлевая салфетка 10x10 (50 шт.)»)
Процедура Медицинские процедуры, выполненные пациенту (лабораторные анализы, визуализация, консультации) Без списания со склада -- процедуры являются платными услугами, а не физическими товарами Позиции каталога процедур с: кодом услуги, названием и ценой в GEL (напр., «24001 - Анализ крови (15.00 GEL)»)

Переключение между режимами очищает поле поиска и любую выбранную позицию, поэтому вы всегда начинаете с чистого листа. Список истории ниже также фильтруется для отображения только соответствующего типа -- расходы показывают только материалы, процедуры показывают только процедуры.

Список истории расходов

Под строкой поиска расположен прокручиваемый список, показывающий все записанные расходы для выбранного пациента (отфильтрованный по текущему режиму). Каждая строка содержит:

  • Наименование -- название расходного материала или процедуры. Строки процедур отображаются жирным синим текстом и являются кликабельными
  • Количество + Ед. изм. -- сколько было использовано (напр., «2 шт.»)
  • Кнопка удаления -- иконка корзины, которая при нажатии показывает диалог подтверждения перед удалением записи и восстановлением складского остатка
Оптимистичные обновления: При добавлении или удалении расхода изменение отображается в списке мгновенно, не дожидаясь ответа сервера. Если серверный запрос завершается с ошибкой, система автоматически откатывает изменение и показывает уведомление об ошибке.

Внизу справа: Детали события

При нажатии на строку процедуры в истории расходов (жирный синий текст) правая панель загружает подпозиции этой процедуры -- конкретные расходные материалы, использованные в рамках данной процедуры.

Заголовок показывает название процедуры. Ниже появляется строка поиска (идентичная левой стороне), позволяющая добавлять дополнительные материалы к выбранной процедуре. Таблица деталей содержит:

Столбец Содержание
Позиция Название расходного материала, использованного в процедуре
Кол-во Использованное количество
Цена за ед. Стоимость за единицу в GEL
Итого Количество, умноженное на цену за единицу
Удалить Удаление этой подпозиции (с подтверждением)

Внизу панели деталей события расположена итоговая строка с градиентным фоном, показывающая общую стоимость всех подпозиций в GEL.

Проверка складских остатков

Система выполняет проверку остатков на стороне клиента перед отправкой расхода. Если вы попытаетесь записать больше единиц, чем доступно, появится предупреждающее уведомление с указанием запрошенного и доступного количества. Расход не отправляется до уменьшения количества до доступного уровня.

FHIR-маппинг: Каждый расход создает ресурс ChargeItem, связанный с Encounter пациента. Подпозиции процедуры также являются ресурсами ChargeItem, связанными с родительской процедурой через расширение parentChargeItemId. Списание со склада обновляет соответствующий ресурс Basic (StockQuant).

1.6 Шаблоны процедур

Некоторые процедуры включают предопределенный список расходных материалов, обычно используемых при их выполнении -- так называемый шаблон расхода. Например, процедура «Ушивание раны» может иметь шаблон со списком: нить для шва, стерильные перчатки, марлевые салфетки и антисептический раствор.

Когда вы добавляете процедуру, имеющую шаблон, система автоматически:

  1. Находит шаблон процедуры (хранится в FHIR-ресурсе ActivityDefinition)
  2. Сопоставляет каждую позицию шаблона с текущим складом отделения по наименованию
  3. Открывает Модальное окно подтверждения шаблона с результатами

Модальное окно подтверждения шаблона

Модальное окно представляет таблицу, где каждая строка соответствует одной позиции из шаблона процедуры:

Столбец Содержание Детали
Чекбокс Выбрать/снять выбор позиции По умолчанию отмечен для доступных позиций. Неактивен (снят) для позиций, отсутствующих на складе
Наименование Название из шаблона + сопоставленная складская позиция Показывает общее название из шаблона (напр., «Марлевая салфетка 10x10») и ниже -- полное название сопоставленной складской позиции (со штрихкодом, поставщиком, партией)
Кол-во по шаблону Количество по умолчанию из шаблона Только для чтения -- предлагаемое количество
Доступно Текущий складской остаток Показывает фактическое количество на складе или прочерк, если позиция не найдена
Итоговое кол-во Редактируемое количество для фактического расхода Числовое поле. Медсестра может изменить в большую или меньшую сторону. Не может превышать доступное количество
Статус Индикатор доступности Зеленый «Доступно», оранжевый «Недостаточно» (остаток меньше шаблонного количества) или серый «Не найдено» (позиция отсутствует на складе отделения)

Позиции со статусом «Не найдено» отображаются с 50% непрозрачностью и неактивным чекбоксом -- их нельзя добавить, так как на складе отделения отсутствует этот расходный материал. Медсестре следует организовать трансфер со склада для получения этих позиций.

Нажмите «Подтвердить» для добавления всех отмеченных позиций как подпозиций процедуры. Каждая подтвержденная позиция уменьшает складской остаток и создает связанный ресурс ChargeItem.

Шаблон -- это рекомендация: Шаблон предоставляет отправную точку, а не фиксированное требование. Медсестры могут снять отметку с неиспользованных позиций, скорректировать количество или полностью закрыть модальное окно. Сама процедура уже зафиксирована независимо от действий с шаблоном.

1.7 Расчеты и отчеты

Модуль расходных материалов отделения включает несколько модальных окон отчетов, доступных через кнопки действий на панели склада. Эти модальные окна предоставляют финансовые сводки, обзоры по отделениям и отчеты для печати.

Модальное окно расчета (кнопка «Калькулятор»)

Модальное окно расчета предоставляет полную финансовую разбивку всех расходных материалов и процедур, использованных выбранным пациентом за период госпитализации. Содержит три вкладки:

Вкладка Содержание Применение
Внутренний расчет Два раздела: «Исследования и консультации» (процедуры) и «Расходные материалы и медикаменты» (расходы). Каждый раздел группирует позиции по отделениям с промежуточными итогами Детальная разбивка расходов для выставления счетов или внутреннего аудита
По отделениям Все позиции (исследования и материалы вместе) объединены и сгруппированы по названию отделения. Каждое отделение показывает свои позиции с промежуточным итогом Сравнение расходов по отделениям -- какое отделение использовало больше всего ресурсов
Интраоперационные Позиции, специально отмеченные как интраоперационный расход (использованные во время хирургических процедур) Учет хирургических расходов, отслеживание материалов операционной

Каждая вкладка содержит таблицу с шестью столбцами: # (номер строки), Наименование, Ед. изм., Количество, Цена за ед. и Итого. Заголовки разделов отображаются на фоне характерного цвета, промежуточные итоги -- в конце каждого раздела. Общий итог внизу показывает совокупную стоимость в GEL.

Кнопка «Печать» открывает расчет в новом окне браузера, отформатированном для печати, включая имя пациента, дату госпитализации и дату выписки (при наличии).

Модальное окно истории отделений (кнопка «H»)

Показывает всех текущих стационарных пациентов, сгруппированных по отделениям. Каждая группа содержит пациентов с датой госпитализации, личным номером, именем и фамилией. Полезно для получения общебольничного обзора распределения пациентов.

Модальное окно снабжения отделения (кнопка «O»)

Показывает историю поставок расходных материалов для текущего отфильтрованного отделения. Каждая строка содержит: Дату, Описание (что было поставлено), Поставщика и Количество. Помогает медсестрам видеть, когда и какие материалы были последний раз доставлены в их отделение.

Модальное окно «Лечение/Исследования» (кнопка «Измерение»)

Сводное модальное окно данных о расходе выбранного пациента, разделенное на две вкладки:

  • Вкладка «Расходные материалы» -- перечисляет все физические расходные материалы (непроцедурные позиции) с датой, наименованием и количеством
  • Вкладка «Исследования» -- перечисляет все записи процедур с датой, наименованием и количеством

Предоставляет быстрый обзор расходов на уровне пациента без полной финансовой детализации модального окна расчета.

Модальное окно дневного баланса (кнопка «Дневной баланс»)

Показывает дневной баланс расхода для выбранного складского отделения. Таблица содержит: Наименование, Количество и Сумму (стоимость в GEL). Внизу три кнопки печати предлагают различные объемы отчета:

Кнопка печати Что печатает
Печать за сегодня Только данные о расходе за сегодня
Печать итого Накопительный расход за весь период госпитализации
Печать комбинированного Данные за сегодня и итого вместе в одном документе
