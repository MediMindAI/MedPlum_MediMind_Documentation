Обзор регистрации пациента

Модуль Регистрации пациента представляет собой комплексную систему, совместимую с FHIR, для регистрации новых пациентов и создания записей о визитах. Он объединяет поиск пациентов, ввод данных на основе форм и управление визитами в единый адаптивный интерфейс, который настраивается для настольных компьютеров, планшетов и мобильных устройств.

Ключевые функции

Система регистрации пациентов обеспечивает комплексные возможности для управления записями пациентов и создания визитов:

Поиск и поиск

  • Единый поиск пациентов - Поиск по личному ID, имени или регистрационному номеру с горячей клавишей (Cmd/Ctrl+K)
  • Расширенные фильтры - Фильтрация по дате рождения, телефону, адресу и другим критериям
  • Двойные результаты действия - Каждый результат предлагает действия "Новый визит" (создание encounter) или "Заполнить форму" (заполнение полей формы)
  • Автопоиск - Поле личного ID автоматически запускает поиск при вводе 11 цифр
  • Обнаружение дубликатов - Предупреждает при создании пациентов с похожими именами или личными ID

Регистрация пациента

  • Проверка личного ID - Грузинский 11-значный личный ID с проверкой контрольной суммы Luhn
  • Режим неизвестного пациента - Экстренная регистрация для пациентов без идентификации (генерирует временный ID)
  • Поддержка опекуна - Автоматические поля опекуна для несовершеннолетних (<18 лет) с ресурсом FHIR RelatedPerson
  • Международный телефон - Ввод номера телефона с селектором кода страны
  • Управление адресом - Каскадные селекторы регион/район/город с грузинскими административными делениями

Управление визитами

  • Переключатель создания визита - Включение/выключение создания визита; при включении показывает 4 дополнительных раздела (Регистрация, Страховка, Гарантия, Демография)
  • Типы визитов - Амбулаторный, Стационарный, Экстренный, с фильтрацией отделений на основе выбора
  • Предупреждение об активном визите - Обнаруживает существующие активные encounters и предупреждает перед созданием дублирующих визитов
  • Регистрационные номера - Автоматически генерируемые последовательные регистрационные номера на encounter
  • Sidebar сегодняшних визитов - Список encounters сегодня в реальном времени со значками статуса и временными метками

Страховка и гарантии

  • Поддержка нескольких страховщиков - Добавьте до 3 страховых компаний на пациента с ресурсами FHIR Coverage
  • Переключатель включения страховки - Условное отображение/скрытие полей страховки
  • Конфигурация доплаты - Установите проценты доплаты, номера полисов, даты выпуска и периоды действия
  • Виртуальный аванс - Система гарантии/депозита с отслеживанием суммы, донора и крайнего срока
  • Вложения документов - Загрузка гарантийных писем и подтверждающих документов

Опыт работы с формой

  • Складывающиеся разделы - 9 разделов аккордеона раскрываются/складываются независимо для уменьшения визуального беспорядка
  • Индикатор прогресса - Визуальный трекер, показывающий статус завершения каждого раздела
  • Автосохранение черновика - Данные формы сохраняются в localStorage каждую 1 секунду, с индикатором значка "Черновик сохранен"
  • Восстановление черновика - Восстановление несохраненных данных формы после перезагрузки браузера или сбоя
  • Липкая кнопка отправки - Кнопка отправки зафиксирована внизу на мобильном для удобного доступа
  • Адаптивный мастер - Мобильный отображает 5-шаговый мастер (Пациент → Личная информация → Контакт → Регистрация → Страховка) вместо аккордеона

Стандарты данных

  • Соответствие FHIR R4 - Все данные хранятся как ресурсы FHIR (Patient, Encounter, Coverage, RelatedPerson, Organization)
  • Привязка данных GoodKey - 101+ сопоставлений кодов для грузинских стандартов здравоохранения
  • Многоязычность - Полная поддержка грузинского, английского и русского языков с переключением языка в реальном времени
  • Доступность - Навигация с клавиатуры, поддержка программ чтения с экрана и соответствие WCAG 2.1 AA
Фильтрация недавних пациентов: Sidebar недавних пациентов автоматически исключает пациентов портала (регистрации портала пациентов) и показывает только зарегистрированных в EMR пациентов, ограничиваясь 10 самыми недавно обновленными записями.
