Функции

Пациент — это постоянная медицинская запись, а Визит (случай обращения) представляет собой одно конкретное посещение больницы. Вы можете зарегистрировать только пациента или зарегистрировать пациента и создать визит одновременно.

1. Поиск пациента

Модуль регистрации включает мощную систему поиска, которая служит основным способом нахождения существующих пациентов.

Компонент главного поиска

Строка главного поиска отображается в верхней части страницы регистрации:

Функция Описание Сочетание клавиш
Быстрый поиск Автоматически определяет, является ли ввод личным номером (11 цифр) или именем Cmd/Ctrl + K
Расширенные фильтры Панель с полями: Личный номер, Имя, Фамилия, Рег. номер Cmd/Ctrl + Shift + K
Навигация по результатам Перемещение по результатам поиска ↑ / ↓
Выбор результата Выбрать выделенный результат Enter
Закрыть поиск Закрыть панель поиска Escape

Панель расширенных фильтров

Нажмите кнопку «Расширенный» или используйте Cmd/Ctrl + Shift + K для открытия детальных фильтров:

  • Личный номер — Личный идентификационный номер (или номер паспорта для иностранных граждан)
  • Имя — Имя пациента
  • Фамилия — Фамилия пациента
  • Регистрационный номер — Внутренний регистрационный номер EMR

Результаты поиска с двойными действиями

При поиске пациента по имени или личному номеру совпадающие результаты отображаются в выпадающем списке с двумя кнопками действий:

Каждый результат поиска отображает две кнопки действий:

Новый визит
Создает новый визит для данного пациента и переходит к деталям визита
Заполнить форму
Заполняет форму регистрации данными пациента для редактирования

Секция поиска пациента

В форме специальное поле позволяет искать пациентов по личному номеру:

Как работает поиск пациента:
  • Введите личный номер пациента
  • Система автоматически выполняет поиск по мере ввода
  • Если найден: отображается карточка пациента с именем, датой рождения и количеством визитов
  • Если не найден: разрешается регистрация нового пациента

Карточка найденного пациента

При нахождении существующего пациента карточка отображает его данные с возможностью редактирования или создания нового визита:

Обнаружение дубликатов

При попытке зарегистрировать пациента с личным номером, который уже существует в системе, появляется окно обнаружения дубликатов:

  • Автоматическая проверка — Срабатывает при вводе личного номера, совпадающего с существующей записью
  • Предварительный просмотр карточки — Показывает имя существующего пациента, дату рождения и историю визитов
  • Варианты действий — Просмотреть существующего пациента, заполнить форму его данными или продолжить новую регистрацию
Предотвращение дубликатов:

Система использует 11-значный грузинский личный номер в качестве уникального идентификатора. При обнаружении совпадения рекомендуется использовать существующую запись, а не создавать дубликат.

2. Форма регистрации

Форма регистрации организована в 9 сворачиваемых секций. Каждую секцию можно развернуть или свернуть для фокусировки на нужных полях.

1
Поиск пациента
Поиск по личному номеру с карточкой пациента
2
Личная информация
Имя, пол, дата рождения, переключатель визита
3
Контактная информация
Телефон, email, адрес
4
Дополнительные данные
Гражданство, семейное положение, место работы
5
Опекун/Представитель
Обязательно для пациентов до 18 лет
6
Регистрация
Детали визита (опционально с переключателем)
7
Страхование
1-3 страховщика с добавлением/удалением
8
Гарантия
Гарантийные письма с загрузкой документов
9
Демография
Регион, жалоба, источник направления

Секция личной информации

Основные данные пациента, собираемые в этой секции:

Поле Тип Обязательно Примечания
Имя Текст Да Имя пациента
Фамилия Текст Да Фамилия пациента
Пол Выбор Да Мужской / Женский / Другой / Неизвестный
Дата рождения Дата Да Должна быть в прошлом
Создать визит Переключатель Нет Показывает/скрывает секции, связанные с визитом

Режим неизвестного пациента

Для экстренных ситуаций, когда личность пациента не может быть установлена, переключатель Неизвестный пациент позволяет выполнить регистрацию без личного номера:

  • Расположение переключателя — Доступен в секции поиска пациента
  • Автоматически сгенерированное имя — Система присваивает временное имя (напр., «Неизвестный пациент #12345»)
  • Автоматически сгенерированный номер — Временный личный номер создается автоматически
  • Последующая идентификация — Запись может быть обновлена после подтверждения личности пациента
Когда использовать режим неизвестного пациента:
  • Экстренная госпитализация, когда пациент без сознания или не может общаться
  • Временная регистрация в ожидании подтверждения личности
  • Иностранные граждане без грузинского личного номера (до ввода паспортных данных)

Поле Тип Обязательно Примечания

Email Email Нет Стандартный формат email
Адрес Текст Нет Полный адрес проживания

Секция дополнительных данных

Поле Тип Обязательно Примечания

Секция опекуна / представителя

Обязательна, когда пациенту менее 18 лет. Система автоматически определяет это на основе даты рождения.

Поле Тип Обязательно Примечания
Имя опекуна Текст Да* *Обязательно для несовершеннолетних
Фамилия опекуна Текст Да* *Обязательно для несовершеннолетних
Личный номер опекуна Текст Да* 11-значный личный номер
Родственная связь Выбор Да* Родитель, Законный опекун и т.д.
Телефон опекуна Тел. Нет Контактный номер

Переключатель создания визита

Форма включает переключатель для управления созданием визита вместе с пациентом:

Создать визит: ВКЛ

Пациент + Визит создаются вместе. Секции Регистрация, Страхование, Гарантия и Демография видимы.

Создать визит: ВЫКЛ

Создается только пациент. Секции, связанные с визитом, скрыты.

Автосохранение черновика

Форма автоматически сохраняет ваш прогресс по мере заполнения:

Функция Поведение
Интервал автосохранения Задержка 1 секунда после любого изменения поля
Индикатор черновика Показывает бейдж «Черновик сохранен» при наличии несохраненных изменений
Очистить черновик Кнопка для удаления сохраненного черновика и сброса формы

3. Детали визита

Когда опция создания визита включена, секции, связанные с визитом, становятся доступными в форме:

Создание нового визита

После нахождения существующего пациента форма отображает его данные и поля регистрации визита для создания нового обращения:

Секция регистрации

Поле Описание
Тип визита Амбулаторный, Стационарный или Экстренный
Дата визита Дата визита
Отделение Целевое отделение/служба
Направляющий врач Врач, направивший пациента (опционально)

Типы визитов

Система поддерживает три типа визитов, каждый с различным рабочим процессом:

Тип Код FHIR Описание Условные поля
Амбулаторный AMB Плановый или незапланированный визит, пациент возвращается домой в тот же день Отделение, Направляющий врач
Стационарный PLAN_STAT Плановая госпитализация для лечения или операции Отделение, Назначение койки, Ожидаемая длительность
Экстренный EMER_STAT Срочная незапланированная госпитализация через приемное отделение Отделение, Уровень триажа

Секция страхования

Добавьте до 3 страховых компаний на один визит:

  • Страховая компания — Выбор из зарегистрированных страховщиков
  • Номер полиса — Номер полиса пациента
  • Тип покрытия — Полное, частичное или специальное покрытие
  • Кнопки Добавить/Удалить — Управление несколькими страховщиками

Секция гарантии

Секция гарантии включает загрузку документов для прикрепления гарантийных писем и сопроводительных документов:

Функции загрузки документов
  • Drag & Drop — Перетаскивайте файлы прямо в зону загрузки
  • Клик для выбора — Нажмите на зону для открытия диалога выбора файлов
  • Множество файлов — До 5 файлов на одну гарантию
  • Множество гарантий — До 3 гарантий на регистрацию
  • Метаданные документа — Название, дата, автор, номер документа
Поле Описание Обязательно
Название документа Описательное название документа Да
Дата документа Дата выдачи документа Да
Автор Лицо или организация, выдавшая документ Нет
Номер документа Регистрационный номер на документе Нет
Файл вложения Сам файл (PDF, изображение и т.д.) Да

Секция демографии

Дополнительные демографические данные, собираемые при регистрации визита:

  • Регион — Регион проживания пациента
  • Основная жалоба — Основная причина визита
  • Источник направления — Как пациент был направлен

Предупреждение об активном визите

Если у пациента уже есть визит в процессе, появляется предупреждающее окно:

Обнаружение активного визита:

Система предотвращает дублирование обращений, обнаруживая визиты в процессе. Вы можете:

  • Просмотреть существующий активный визит
  • Создать новый визит в любом случае (с подтверждением)
  • Отменить и вернуться к форме

5. Мобильный мастер

На экранах уже 768px форма трансформируется в 5-шаговый мастер для удобной мобильной навигации:

1
Пациент
Поиск + Личная информация
2
Детали
Контакты + Дополнительно + Опекун
3
Визит
Детали регистрации (если включено создание визита)
4
Страхование
Страхование + Гарантия (если включено создание визита)
5
Подтверждение
Демография + Сводка

Поток шагов мастера

flowchart LR S1[Step 1: Patient] --> S2[Step 2: Details] S2 --> S3[Step 3: Visit] S3 --> S4[Step 4: Insurance] S4 --> S5[Step 5: Confirm]
Поведение мобильного мастера:
  • На мобильных устройствах 9 секций формы группируются в 5 шагов для удобной навигации
  • Шаги 3 и 4 скрыты, когда переключатель создания визита ВЫКЛ
  • Индикатор прогресса показывает текущий шаг
  • Кнопки Назад/Далее для навигации между шагами
  • Автосохранение черновика работает на всех шагах
