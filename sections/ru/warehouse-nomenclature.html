Иерархия продукции

Перекрёстная фильтрация

Ключевая функция номенклатурной системы - перекрёстная фильтрация. Нажатие на элемент на любом уровне автоматически фильтрует следующий нижний уровень:

  • Нажмите на Группу продукции, чтобы увидеть только Общие наименования, принадлежащие этой группе
  • Нажмите на Общее наименование, чтобы увидеть только товары Каталога продукции для этого продукта
  • Активные фильтры отображаются в виде значков в верхней части страницы и могут быть очищены по отдельности или все сразу

Категории и группы

Первые три уровня иерархии обеспечивают организационную структуру для всех складских товаров.

Категории (Уровень 1)

Категории - это самая широкая классификация. Система поставляется с предварительно настроенными стандартными категориями больничного склада: Расходные материалы, Медикаменты, Хозяйственные товары, Реагенты и Медицинские инструменты.

Каждая вкладка категории предоставляет:

  • Добавление нового — Введите название и нажмите Enter или кнопку добавления
  • Поиск — Фильтрация списка путём ввода в строку поиска
  • Редактирование на месте — Нажмите кнопку редактирования в любой строке для переименования прямо в таблице
  • Удаление — Удаление элементов с диалогом подтверждения для предотвращения случайного удаления
  • Индикатор статуса — Зелёная точка для активных элементов, серая для неактивных
  • Постраничная навигация — 25 элементов на страницу для быстрой загрузки

Группы продукции (Уровень 2)

Группы продукции организуют товары внутри категорий. Каждая группа принадлежит родительской категории и отслеживает количество содержащихся Общих наименований.

Вкладка Группы добавляет эти функции помимо стандартного списка:

  • Столбец Родительская категория — Показывает, к какой категории принадлежит каждая группа
  • Значок Количество элементов — Отображает количество Общих наименований в каждой группе
  • Навигация по клику на строку — Нажмите на любую строку группы для перекрёстной фильтрации к её Общим наименованиям
  • Выбор категории — При добавлении новой группы можно назначить родительскую категорию
ℹ️
Подгруппы (Уровень 3) обеспечивают необязательную более детальную классификацию внутри Групп продукции. Они работают так же, как Категории и Группы, но используются реже. Вкладка Подгруппы следует тому же шаблону добавления/поиска/редактирования/удаления.

Каталог продукции

Два нижних уровня содержат фактические данные о продуктах, используемые в повседневных складских операциях.

Общие наименования (Уровень 4)

Общие наименования представляют стандартные названия продуктов без указания бренда или производителя. Например, "Амоксициллин" - это общее наименование, а "Амоксициллин 500мг Таблетка производства GlaxoSmithKline" - конкретный товар каталога.

Вкладка Общие наименования показывает:

  • Значок подгруппы — К какой подгруппе (или группе продукции) принадлежит этот элемент
  • Количество на складе — Число конкретных товаров каталога, связанных с этим общим наименованием
  • Уведомление о фильтре группы — При перекрёстной фильтрации из Группы продукции синее уведомление показывает активный фильтр с кнопкой очистки
  • Навигация по клику на строку — Нажмите на любое общее наименование для перекрёстной фильтрации к его товарам Каталога продукции

Каталог продукции (Уровень 5)

Каталог продукции - самый детальный уровень, содержащий конкретные складские товары с полными атрибутами. Здесь вы управляете фактическими продуктами, которые хранятся, распределяются и отслеживаются в больнице.

Таблица каталога содержит 13 столбцов с исчерпывающей информацией о товаре:

Каталог поддерживает серверную постраничную навигацию (50 элементов на страницу) и предоставляет три элемента управления фильтрами:

  • Текстовый поиск — Фильтрация по названию продукта с задержкой ввода (300 мс для производительности)
  • Фильтр категории — Выпадающий список для фильтрации по категории верхнего уровня
  • Фильтр статуса — Показать активные товары, удалённые товары или все
Примечание: Удалённые товары отображаются с красной подсветкой в таблице. Товары удаляются "мягко" (помечаются как удалённые), а не безвозвратно, что сохраняет журнал аудита для соответствия требованиям.

Нажмите кнопку редактирования на любом товаре каталога, чтобы открыть подробное модальное окно редактирования. Модальное окно имеет две вкладки:

Вкладка Основное содержит редактируемые разделы, каждый со своей кнопкой Сохранить:

Медицинский товар Название медицинского товара (автозаполнение) Связывает этот товар каталога с Общим наименованием Уровня 4

Вкладка Атрибуты показывает дочерние товары, связанные с этим продуктом (для составных или комплектных товаров).

ℹ️
Повышенная аутентификация: Сохранение изменений в товарах каталога требует повторной аутентификации. При нажатии кнопки Сохранить появляется диалог подтверждения с запросом проверки учётных данных перед применением изменения. Это защищает от несанкционированных модификаций базы данных продуктов.
Детали модели данных FHIR

Иерархия номенклатуры реализована с использованием следующих ресурсов FHIR:

  • List (с различными значениями code) — Хранит уровни 1-4 как записи списка. Каждая запись содержит имя элемента и статус. Отношения родитель-потомок поддерживаются через ссылки записей.
  • SupplyDelivery — Хранит товары каталога Уровня 5 с полными атрибутами (код, название, категория, единица, количество). Расширения FHIR несут дополнительные данные: производитель, правила ценообразования и связи с группами.
  • DeviceDefinition — Используется для модального окна редактирования, предоставляя детальные атрибуты: НДС, фармацевтические детали, уровни запасов, отслеживание партий и история транзакций.
