1

Обзор номенклатуры продукции

Модуль Номенклатура склада представляет собой центральный каталог продукции для всей цепочки поставок больницы. Его можно сравнить с главной библиотекой продукции больницы -- каждый медикамент, расходный материал, оборудование и предмет снабжения, используемый во всех отделениях, организован здесь в структурированной, легко находимой иерархии.

Подобно тому, как библиотека использует систему классификации (полки, разделы, подразделы и отдельные книги), номенклатура склада организует продукцию в 5 иерархических уровней. Это позволяет легко найти любой товар среди десятков тысяч наименований и обеспечивает единообразие наименований и группировки во всех отделениях.

Соответствие FHIR R4: Все данные номенклатуры хранятся с использованием ресурсов FHIR R4. Категории, группы, подкатегории и международные непатентованные наименования используют ресурсы List, а отдельные складские товары -- ресурсы SupplyDelivery. Модальное окно редактирования товара использует DeviceDefinition для расширенных атрибутов продукции.

5-уровневая иерархия продукции

Каждый товар в больнице принадлежит к 5-уровневому классификационному дереву. Каждый уровень добавляет более детальную специфику -- от широких категорий до конкретного товара с точным указанием бренда, упаковки и данных поставщика.

Панель вкладок в верхней части страницы отображает каждый уровень в виде кликабельной карточки. На десктопе иконка шеврона между карточками показывает связь «родитель-потомок» (на мобильных устройствах скрыта, где карточки отображаются в виде сетки). На каждой карточке отображается счетчик с количеством элементов на данном уровне. Нажатие на карточку переключает вид на таблицу управления соответствующего уровня.

Сворачиваемая информационная панель: Нажмите на панель «Как работает эта иерархия?» в верхней части страницы, чтобы развернуть встроенное справочное руководство. В нем показаны назначение, описание и примеры элементов каждого уровня без необходимости покидать страницу.

2

Категории (Уровень 1)

Категории -- это самый широкий уровень классификации, верхние «полки» в вашей библиотеке продукции. Они делят весь инвентарь больницы на основные функциональные группы: Медикаменты, Расходные материалы, Оборудование и Питание. Система поставляется с 11 предустановленными категориями, и администраторы могут добавлять собственные.

Эти 11 складских групп (унаследованные из устаревшей системы больницы) представляют самую широкую классификацию всех товаров снабжения:

Название группы Примеры

Медикаменты Таблетки, инъекции, сиропы, мази
Хозяйственные товары Моющие средства, бумажные полотенца, мыло
Неинвентарные товары Товары одноразового использования, не учитываемые в инвентаре
Основные средства Мебель, тяжелое оборудование, транспортные средства

Управление категориями

Вкладка «Категории» предоставляет простой интерфейс для просмотра и управления категориями верхнего уровня:

  • Добавить категорию -- Введите название в форме «Добавить» и нажмите кнопку + (или клавишу Enter). Новая категория сразу появится в списке.
  • Поиск -- Используйте строку поиска для фильтрации категорий по названию в реальном времени.
  • Редактирование -- Нажмите значок редактирования (карандаш) в любой строке. Название станет редактируемым текстовым полем. Нажмите Enter или щелкните в другом месте для сохранения.
  • Удаление -- Нажмите значок удаления (корзина). Перед удалением категории появится диалоговое окно подтверждения.
  • Статус -- Каждая категория отображает значок статуса «активна/неактивна» с цветным индикатором.
Внимание: Удаление категории не приводит к автоматической переклассификации назначенных ей товарных групп. Перед удалением переназначьте товарные группы в другую категорию, чтобы избежать «осиротевших» записей.
3

Товарные группы (Уровень 2)

Товарные группы -- это второй уровень иерархии. Если категории -- это «полки», то товарные группы -- это подписанные секции на каждой полке. Они представляют собой функциональные группировки внутри категории. Например, в категории «Медикаменты» могут быть группы «Антибиотики», «Анальгетики» и «Сердечно-сосудистые».

Система содержит более 310 товарных групп, и каждая из них может опционально принадлежать родительской категории.

Родительская категория К какой категории Уровня 1 принадлежит группа, отображается со значком метки. Показывает «-», если не назначена.
Количество элементов Синий значок с числом МНН (элементов Уровня 4) в данной группе

Добавление товарной группы

  1. Введите название группы в текстовое поле.
  2. При необходимости выберите Родительскую категорию из выпадающего списка с поиском. Это связывает группу с категорией Уровня 1.
  3. Нажмите кнопку + или клавишу Enter.

Перекрестная фильтрация

Одна из самых мощных функций модуля номенклатуры -- перекрестная фильтрация. При нажатии на строку товарной группы система автоматически:

  1. Переключается на вкладку МНН (Уровень 4)
  2. Фильтрует список, показывая только МНН, принадлежащие данной группе
  3. Отображает синюю панель фильтра вверху, указывая, какая группа выбрана

Это позволяет быстро углубиться от широкой группы до конкретных позиций без ручного переключения вкладок и поиска. Нажмите кнопку X на панели фильтра, чтобы сбросить фильтр и снова увидеть все элементы.

Быстрый поиск: Вы также можете искать группы по названию с помощью строки поиска в верхней части таблицы. Поиск применяется в реальном времени по мере ввода текста.

Подгруппы (Уровень 3)

Подгруппы обеспечивают третий уровень детализации внутри каждой товарной группы. Если товарные группы делят категорию на функциональные области (напр., «Антибиотики»), то подгруппы разбивают эти области ещё подробнее (напр., «Цефалоспорины», «Пенициллины», «Макролиды»). Такая дополнительная детализация помогает фармацевтам и сотрудникам отдела закупок быстрее находить нужные позиции.

Вкладка «Подгруппы» следует той же структуре, что и «Категории» и «Товарные группы»:

Столбец Описание
Код Внутренний код подгруппы (отображает «-», если не задан)
Название Название подгруппы (редактируется inline)
Родительская категория Товарная группа Уровня 2, к которой принадлежит данная подгруппа
Статус Значок статуса «активна» или «неактивна»

Для добавления новой подгруппы введите название, выберите родительскую товарную группу из выпадающего списка и нажмите +.

Примечание: Перекрестная фильтрация из строк подгрупп на вкладку «МНН» определена в интерфейсе компонента, но в настоящее время не подключена в основном представлении. Нажатие на строку подгруппы пока не вызывает навигацию.
4

МНН и каталог продукции

Последние два уровня приводят нас к уровню отдельного товара. Международные непатентованные наименования (МНН) (Уровень 4) -- это стандартизированные медицинские наименования, то есть «что это такое» без указания бренда. Каталог продукции (Уровень 5) содержит фактические складские товары с конкретными брендами, дозировками, поставщиками и упаковкой.

МНН (Уровень 4)

МНН представляют более 500 стандартизированных медицинских наименований. Каждое МНН принадлежит подгруппе (Уровень 3) и объединяет один или несколько конкретных складских товаров. Например, МНН «Цефтриаксон» может включать 15 складских товаров от разных производителей и в разных размерах упаковки.

Таблица содержит четыре столбца:

Столбец Описание
Название Стандартизированное МНН. Рядом с каждым названием отображается значок шеврона, указывающий, что по нему можно кликнуть для перекрестной фильтрации.
Подгруппа Подгруппа Уровня 3, к которой принадлежит данный элемент, отображается синим значком
Кол-во на складе Бирюзовый значок, показывающий сколько конкретных складских товаров ссылаются на данное МНН
Статус Значок статуса «активен» или «неактивен» (скрыт на мобильных устройствах)

Когда активен фильтр группы (после нажатия на строку товарной группы на Уровне 2), в верхней части появляется синяя панель уведомления, показывающая выбранную группу, с кнопкой закрытия для сброса фильтра.

Нажатие на строку МНН запускает вторую перекрестную фильтрацию: система переключается на вкладку «Каталог продукции» и фильтрует её, показывая только товары с данным МНН. Это создает плавный поток детализации: Группа > МНН > Конкретные товары.

Каталог продукции (Уровень 5)

Каталог продукции -- это самый большой и подробный уровень, содержащий более 36 500 индивидуальных товарных записей. Именно здесь определяется каждый конкретный товар в инвентаре больницы -- с точным наименованием, кодом, производителем, единицей измерения и категорией.

Таблица каталога продукции содержит 13 столбцов с горизонтальной прокруткой для отображения всех полей данных. Для полного отображения таблицы требуется минимальная ширина 1800 пикселей.

Поиск и фильтры

Каталог продукции предоставляет три элемента управления фильтрацией в горизонтальном ряду над таблицей:

  • Поиск -- Поиск в реальном времени по наименованию товара. Поиск имеет задержку (300 мс), чтобы избежать избыточной фильтрации при вводе текста. (Поиск по штрихкоду доступен отдельно через сервис интеграции RS.ge, а не через основную строку поиска.)
  • Фильтр по категории -- Выпадающий список для фильтрации по складской группе (Расходные материалы, Медикаменты и т.д.). Выберите «Все», чтобы увидеть все категории.
  • Фильтр по статусу -- Выпадающий список для отображения только активных товаров, только удаленных или всех товаров. По умолчанию установлено «Активные».
Серверная пагинация: Поскольку каталог продукции содержит более 36 500 позиций, таблица использует серверную пагинацию по 50 элементов на странице. Счетчик количества в области подзаголовка показывает «X / Всего» (напр., «50 / 36 513»), а стандартные элементы управления пагинацией расположены внизу. Данные загружаются по запросу при переходе между страницами, чтобы избежать загрузки всего набора данных.

Индикатор перекрестного фильтра

Когда вы попадаете в каталог продукции через перекрестную фильтрацию (переход от группы или МНН), появляются два индикатора фильтра:

  • Панель фильтра на уровне страницы (в верхней части всей страницы номенклатуры) -- Показывает синий значок выбранной товарной группы (Уровень 2), шеврон-разделитель и бирюзовый значок выбранного МНН (Уровень 4). У каждого значка есть собственная кнопка закрытия для индивидуального сброса фильтра. Справа расположена общая кнопка сброса для удаления всех фильтров одновременно.
  • Уведомление на уровне вкладки (внутри вкладки «Каталог продукции») -- Более простой синий компонент Alert с inline текстом значков и одной кнопкой закрытия для полного сброса перекрестного фильтра.

Добавление нового товара

Нажмите кнопку «Добавить товар» над таблицей, чтобы открыть модальное окно создания товара. Если вы перешли через перекрестный фильтр, поля группы и МНН заполняются автоматически.

Модальное окно создания включает следующие поля:

  • Наименование товара -- Полное наименование товара (обязательное поле).
  • Код товара -- Внутренний код для идентификации.
  • Товарная группа и МНН -- Предзаполнены при переходе через перекрестный фильтр; в противном случае выберите из выпадающих списков с поиском.
  • Категория, Единица измерения, Производитель -- Данные классификации и упаковки.

Действия со строками

Для каждой строки товара доступны два действия через столбец кнопок действий:

  • Редактировать (значок карандаша) -- Открывает полное модальное окно редактирования товара (см. Раздел 5 ниже)
  • Удалить (значок корзины) -- Выполняет мягкое удаление товара после подтверждения. Удаленные строки выделяются красным, если фильтр статуса включает удаленные товары.
5

Модальное окно редактирования товара

Нажатие значка редактирования в любой строке товара открывает полноширинное модальное окно с детальной конфигурацией продукта. Здесь сотрудники больницы могут управлять всеми расширенными атрибутами товара -- от фармацевтических данных до параметров управления запасами.

Модальное окно организовано в две вкладки:

Вкладка «Основное»

Вкладка «Основное» содержит основные атрибуты товара, организованные в отдельные секции. Каждая секция имеет собственную кнопку «Сохранить», позволяющую сохранить изменения в одной секции без влияния на другие. Такой подход посекционного сохранения предотвращает случайную перезапись данных, когда несколько пользователей редактируют один и тот же товар.

Повторная аутентификация: Сохранение любой секции в модальном окне редактирования требует повторной аутентификации. При нажатии кнопки «Сохранить» появляется диалоговое окно подтверждения пароля. Это защищает критически важные данные о товарах от несанкционированных изменений.

1 Базовая конфигурация Флажок VAT, информация о родительском ID Установить, применяется ли VAT к данному товару, и просмотреть ссылки на родительский товар
2 Запасы по отделениям Таблица запасов (только для чтения) Показывает текущие уровни запасов по отделениям больницы. Отображается только при наличии данных о запасах.
3 Медицинское наименование Автозаполнение медицинского наименования или текстовый ввод Привязать данный товар к МНН Уровня 4. Включает кнопки «Сохранить» и «Очистить».
4 Товарная группа Название группы (редактируемый текст) Показывает или переопределяет товарную группу Уровня 2. Заполняется автоматически при выборе медицинского наименования.
5 Дженерик Автозаполнение наименования дженерика Привязка к наименованию дженерика для фармацевтических товаров (напр., Парацетамол, Ибупрофен)
6 Разбивка товара Количество, единица измерения Определить, как данный товар разбивается на более мелкие единицы (спецификация состава)
7 Медицинская рубрика Текст рубрики, страна (ISO 3166), производитель Вторичная медицинская классификация, страна происхождения и ссылка на производителя
8 Метки Селектор меток категории, код UNSPSC Назначение классификационных меток (Наркотик, Антибиотик, Иммунологический и т.д.) и кодов товарной номенклатуры UNSPSC
9 Расчет цены Селектор режима цены Управляет отображением товара в платежных сводках и/или клинических расчетах
10 Фармацевтические данные Лекарственная форма, дозировка, путь введения, признак контролируемого вещества Поля, специфичные для лекарственных средств. Видны только когда категория товара -- «Медикаменты» или «Контролируемые вещества».
11 Запасы и отслеживание Мин./макс. уровни запасов, время выполнения заказа, отслеживание партий, отслеживание сроков годности, срок хранения Настройка параметров управления запасами для автоматических оповещений о дозаказе и отслеживания партий/сроков годности
12 История транзакций Таблица последних 50 транзакций (только для чтения) Просмотр последних движений запасов по данному товару (поступления, перемещения, расход)

Вкладка «Атрибуты»

Вкладка «Атрибуты» содержит таблицу Дочерние товары, показывающую все товары, которые ссылаются на данный товар как на родительский. Это полезно для составных или комплектных товаров, где один основной товар состоит из нескольких подкомпонентов.

Справочник меток категорий

Метка Назначение
Наркотик Контролируемые вещества, требующие специального отслеживания и отчетности
Антибиотик Антибактериальные препараты для программ антимикробного контроля
Гуманитарные товары Пожертвованные товары или товары гуманитарной помощи
Иммунологический Вакцины и иммунологические препараты
Коагуляция Лабораторные реактивы для тестов на свертываемость крови
Биохимия Лабораторные реактивы для биохимических панелей
Клинический Общие расходные материалы для клинических исследований
Одноразовые лабораторные материалы Одноразовые лабораторные расходные материалы
Калибраторы и контроли Материалы для контроля качества и калибровки
Вспомогательные растворы Вспомогательные растворы для лабораторного оборудования
Сверхстандартный материал (Имплант) Высокостоимостные имплантируемые медицинские изделия
MRI Контрастные вещества и расходные материалы для MRI

Поля управления запасами

Секция «Запасы и отслеживание» (Секция 11) предоставляет поля для настройки автоматизированного управления запасами:

Поле Описание Расширение FHIR
Мин. уровень запасов Когда текущий запас падает ниже этого значения, срабатывает оповещение о дозаказе. Не может превышать максимальный уровень запасов. min-stock-level
Макс. уровень запасов Максимальное количество товара на складе. Используется калькулятором точки дозаказа для определения объемов заказа. max-stock-level
Время выполнения (дни) Количество дней между размещением дозаказа и получением поставки. Используется для расчета момента дозаказа. lead-time-days
Обязательное отслеживание партий При включении каждое поступление и перемещение данного товара должно содержать номер партии. lot-tracking-required
Обязательное отслеживание сроков годности При включении каждое поступление должно содержать дату окончания срока годности. Активирует комплектацию по методу FEFO (первым истекает -- первым отгружается). expiration-tracking-required
Срок хранения по умолчанию (дни) Появляется только при включенном отслеживании сроков годности. Устанавливает срок хранения по умолчанию для товаров, поступивших без указания даты окончания срока годности. default-shelf-life-days
Фармацевтические данные: Поля лекарственной формы, дозировки, пути введения и контролируемого вещества отображаются только когда категория товара установлена как «Медикаменты» или «Контролируемые вещества». Для нефармацевтических товаров эта секция скрывается автоматически.
