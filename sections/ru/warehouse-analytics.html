Аналитика остатков

Аналитика остатков -- это наиболее комплексный инструмент отчетности в складском модуле MediMind. Представьте его как центр аналитики цепочки поставок вашей больницы -- он берет необработанные данные операций (приемки, трансферы, списания, выдачи) и преобразует их в практические выводы по 9 специализированным вкладкам.

Руководители больницы используют эту страницу для ответа на критические вопросы: «Куда уходят наши деньги? Какие товары простаивают? Чего нам не хватит в следующем месяце? Какие поставщики доставляют вовремя?» Вместо формирования отчетов в таблицах, вся информация доступна в реальном времени на одной странице.

1.1 Глобальные фильтры

В верхней части страницы аналитики расположена сворачиваемая панель фильтров, управляющая отображением данных на всех вкладках ниже. Установка фильтров здесь применяет их ко всем вкладкам -- вам не нужно повторно фильтровать при переключении между «Таблицей остатков», «Аналитикой» и другими представлениями.

Диапазон дат

Два поля выбора даты позволяют определить период анализа. Поле «С» устанавливает начальную точку, а поле «По» -- конечную. Система автоматически не позволяет выбрать конечную дату раньше начальной.

Быстрые пресеты

Под полями выбора дат расположен ряд кнопок-капсул, предоставляющих быстрый доступ к типичным временным диапазонам. Нажатие на пресет автоматически заполняет оба поля дат:

Пресет Применяемый диапазон Типичное применение
Сегодня Только текущая дата Проверка остатков на конец дня
Эта неделя С понедельника по сегодня Еженедельный обзор активности
Этот месяц С 1-го числа текущего месяца по сегодня Ежемесячная отчетность
Прошлый месяц Полный предыдущий календарный месяц Сравнение по завершенному месяцу

Фильтры отделений и групп

Два выпадающих списка с множественным выбором позволяют сузить анализ до конкретных отделений или категорий:

  • Отделение -- выберите одно или несколько отделений больницы (напр., Скорая помощь, Хирургия, Реанимация). Выпадающий список поддерживает поиск и очистку всех выбранных значений
  • Категория -- выберите одну или несколько категорий товаров (напр., Медикаменты, Расходные материалы, Реагенты). Полезно для анализа конкретной категории расходных материалов

На панели фильтров отображается индикатор количества активных фильтров, показывающий, сколько фильтров применено, чтобы вы всегда знали, когда данные отфильтрованы.

Нажмите «Поиск» для применения: После изменения любых фильтров необходимо нажать кнопку «Поиск» для их применения. Простой выбор даты или отделения не перезагружает данные автоматически -- это сделано намеренно, чтобы избежать лишней нагрузки на сервер при настройке нескольких фильтров.

1.2 Панель KPI

После выполнения поиска под фильтрами появляется ряд KPI-карточек, дающих мгновенную оценку состояния вашего склада за выбранный период. Карточки расположены в два ряда по четыре:

KPI-карточка Что показывает Как интерпретировать
Общая стоимость запасов Общая денежная стоимость всех товаров на складе (в GEL) Рост стоимости без соответствующей активности может указывать на затоваривание
Всего наименований Количество уникальных позиций, по которым было движение за период Сравните с общим каталогом, чтобы увидеть, сколько позиций активны
Сумма закупок Общая сумма всех закупок (поступлений от поставщиков) Сопоставьте с бюджетом для контроля расходов на закупки
Сумма выдач Общая сумма товаров, выданных пациентам или использованных Основной показатель того, насколько расходные материалы обеспечивают уход за пациентами
Неликвидные позиции Количество позиций без движения, но с положительным остатком Высокое число указывает на замороженный капитал в неиспользуемых запасах
Низкий запас Количество позиций, опустившихся ниже безопасного уровня запаса Эти позиции требуют внимания по дозаказу до того, как закончатся
Ср. дней запаса Среднее количество дней, на которое хватит текущего запаса при текущем уровне потребления Менее 14 дней свидетельствует о системном риске нехватки
Коэф. оборачив. Сколько раз запасы были «обернуты» (проданы и восполнены) за период Чем выше, тем лучше -- это означает, что расходные материалы движутся эффективно

При наличии данных отображается девятая карточка -- Уровень исполнения -- процент запрошенных позиций, которые были успешно выполнены. Уровень исполнения ниже порогового значения отображается красным цветом, сигнализируя о проблемах с выполнением заказов.

Источники данных FHIR: Значения KPI вычисляются на основе ресурсов Basic (StockQuant) для текущих остатков, SupplyDelivery для истории движений (поступления, трансферы, списания) и SupplyRequest для показателей исполнения заказов. Данные кешируются на 30 секунд для баланса между точностью и производительностью.

1.3 Таблица остатков

Вкладка «Таблица остатков» -- это наиболее насыщенное данными представление в системе аналитики. Она представляет полную ведомость, показывающую для каждой позиции начальный остаток, все поступления и расходы, а также конечный остаток за выбранный период -- аналогично финансовому оборотно-сальдовому отчету, но для складских запасов.

Группы столбцов с цветовой кодировкой

Таблица организует свои 22+ столбцов в группы с цветовой кодировкой, чтобы вы могли быстро найти нужную информацию:

Группа столбцов Цвет Столбцы Что отслеживает

Подсветка строк

Таблица автоматически выделяет строки, требующие внимания:

  • Строки с красным оттенком -- позиции с нулевым конечным остатком (дефицит). Эти товары закончились и могут влиять на качество медицинской помощи
  • Строки с желтым оттенком -- неликвидные позиции: положительный конечный остаток, но нулевое движение за период. Капитал заморожен в этих позициях без какого-либо использования

Индикаторы запаса в днях

Столбец «Запас в днях» использует систему светофора для отображения срочности:

  • Красный индикатор (<7 дней) -- Критично. При текущем уровне потребления запас закончится в течение недели
  • Желтый индикатор (7-30 дней) -- Внимание. Запас ограничен, но не критически мал
  • Зеленый индикатор (>30 дней) -- Норма. Достаточный запас как минимум на месяц
  • Серый индикатор «Н/Д» -- Позиция есть в наличии, но нет активности выдачи, поэтому запас в днях невозможно рассчитать
  • Отображение «999+» -- Более 999 дней запаса (фактически избыточный запас)

Индикаторы классификации ABC

Каждой позиции автоматически присваивается класс ABC на основе стоимости её выдачи относительно всех позиций:

  • A (красный индикатор) -- Первые 80% от общей стоимости выдачи. Это ваши наиболее ценные позиции, заслуживающие пристального внимания
  • B (желтый индикатор) -- Следующие 15% стоимости. Важные, но менее критичные, чем позиции класса A
  • C (зеленый индикатор) -- Оставшиеся 5% стоимости. Малоценные позиции, которые можно контролировать проще

Встроенный поиск и итоги

  • Поля «Поиск по коду» и «Поиск по наименованию» над таблицей позволяют фильтровать позиции без изменения глобальных фильтров
  • Закрепленная итоговая строка внизу суммирует все столбцы количества и сумм, прокручиваясь горизонтально синхронно с основной таблицей
  • Заголовки столбцов содержат подсказки, объясняющие, что измеряет каждый столбец -- наведите курсор на любой заголовок для просмотра описания

1.4 Аналитика

Вкладка «Аналитика» представляет четыре сводных представления, помогающих руководителям быстро понять закономерности складской деятельности без погружения в необработанные данные. Представьте его как «резюме для руководства» ваших складских операций.

Топ-10 позиций по стоимости

Рейтинговый список, показывающий десять самых ценных позиций на вашем складе. Для каждой позиции отображается наименование, общая стоимость и пропорциональная полоса прогресса (позиция №1 заполняет полосу на полную ширину, остальные масштабируются относительно неё). Это немедленно отвечает на вопрос: «Где сосредоточена большая часть нашего складского капитала?»

Сводка движений

Таблица из шести строк, агрегирующая все движения запасов за выбранный период:

Тип движения Что представляет
Закупки Общее количество и стоимость товаров, полученных от поставщиков
Трансферы (приход) Товары, полученные из других отделений
Трансферы (расход) Товары, отправленные в другие отделения
Возвраты Товары, возвращенные поставщикам
Списания Товары, списанные из-за истечения срока годности, повреждения или других потерь
Выдано Товары, использованные для ухода за пациентами

Сравнение периодов

Сравнивает текущий период с предыдущим периодом равной длительности. Например, если вы выбрали «Этот месяц», он сравнивается с прошлым месяцем. Сравниваются три ключевых показателя:

  • Закупки -- Покупаем ли мы больше или меньше, чем раньше?
  • Выдано -- Растет или снижается потребление?
  • Общая стоимость запасов -- Растет или уменьшается стоимость наших запасов?

Каждый показатель отображается с индикатором процентного изменения: зеленый для роста, красный для снижения, синий при отсутствии изменений.

Активность отделений

Визуальная разбивка поступлений vs расходов по отделениям. Для каждого отделения показаны две горизонтальные полосы:

  • Зеленая полоса -- Поступления (стоимость расходных материалов, полученных отделением)
  • Желтая полоса -- Расходы (стоимость расходных материалов, отправленных или использованных)

Отделения, где полоса расходов значительно превышает полосу поступлений, могут потреблять быстрее, чем получают пополнение.

1.5 Неликвидные запасы и низкий запас

Эти две вкладки выявляют позиции на противоположных концах спектра складского здоровья: позиции, которые вообще не движутся (неликвид), и позиции, запас которых опасно мал (низкий остаток). Обе таблицы сортируются по любому столбцу.

Вкладка «Неликвидные запасы»

Неликвидные позиции имеют положительный конечный остаток (они есть на вашем складе), но не имели абсолютно никакого движения за выбранный период -- ни закупок, ни трансферов, ни выдачи, ничего. Они представляют собой капитал, который лежит без движения.

Столбец Описание
Код / Наименование / Ед. изм. Идентификация позиции
Конечное кол-во Сколько единиц лежит на складе
Конечная сумма Денежная стоимость неподвижного запаса (в GEL)
Дней с последнего движения Сколько дней прошло с последней операции. Позиции, по которым никогда не было движения, отмечены красным индикатором «Не перемещался»
Действия по неликвидным запасам: Позиции с меткой «Не перемещался» могли быть введены ошибочно или приняты не на то отделение. Проверьте эти позиции на наличие ошибок данных и рассмотрите возможность трансфера неиспользуемых товаров в отделения, которые могут в них нуждаться, до истечения срока годности.

Вкладка «Низкий запас»

Позиции с низким запасом имеют положительный баланс, но их конечное количество менее 5 единиц. Столбец «Запас в днях» показывает, на сколько дней хватит текущего запаса, однако сам фильтр низкого запаса выявляет позиции с конечным количеством ниже этого порога.

Столбец «Запас в днях» использует цветовую кодировку текста:

  • Красный текст (<7 дней) -- Критическая нехватка. Дозакажите немедленно
  • Желтый текст (7-30 дней) -- Мало, но не критично. Запланируйте дозаказ
  • Зеленый текст (>30 дней) -- Здоровый уровень запаса
  • «999+» -- Фактически неограниченный запас при текущем потреблении (возможное затоваривание)

1.6 Классификация ABC/XYZ

Вкладка ABC/XYZ применяет известную методику управления запасами, которая классифицирует каждую позицию по двум измерениям: сколько она стоит (ABC) и насколько предсказуемо её потребление (XYZ). Результатом является матрица 3x3, показывающая, какие позиции требуют наибольшего управленческого внимания.

Понимание осей

Интерактивная матрица

Сетка 3x3 является кликабельной. Каждая ячейка показывает количество позиций в данной классификации и их совокупные годовые расходы. Нажмите на любую ячейку, чтобы отфильтровать таблицу ниже и показать только позиции этой классификации. Нажмите снова для отмены выбора.

Ячейки имеют цветовую кодировку по приоритету управления -- ячейки в верхнем левом углу (AX: высокая стоимость, стабильный спрос) выделяются иначе, чем ячейки в нижнем правом углу (CZ: низкая стоимость, нестабильный спрос).

1.7 Срок годности

Вкладка «Срок годности» помогает предотвратить потери, показывая, какие позиции приближаются к дате истечения срока годности. Позиции группируются в пять временных интервалов, чтобы вы могли расставить приоритеты действий по степени срочности.

Каждая карточка показывает как количество позиций, так и общую стоимость под риском (денежную стоимость товаров, которые могут быть потеряны при истечении срока годности без использования).

Детализирующая таблица

Нажмите на любую карточку интервала, чтобы увидеть подробную таблицу позиций в этом временном окне:

  • Код / Наименование позиции -- идентификация позиции
  • Номер партии -- конкретная партия с истекающим сроком
  • Отделение -- где сейчас хранится позиция
  • Количество / Цена за единицу / Стоимость под риском -- финансовое влияние при истечении срока
  • Срок годности -- фактическая дата истечения
  • Индикатор «Осталось дней» -- цветовая кодировка: красный для 7 дней и менее, желтый для 8-30 дней, синий для более 30 дней

Сводка по отделениям

Под таблицей расположена горизонтальная столбчатая диаграмма, показывающая распределение риска истечения сроков по отделениям. Это помогает выявить, не содержит ли одно отделение непропорционально большую долю товаров с истекающим сроком.

1.8 Поставщики и операции

Вкладка «Поставщики и операции» предоставляет четыре различных аналитических раздела, расположенных вертикально. Вместе они отвечают на вопросы: «Кто наши поставщики? Как они работают? Где мы теряем запасы? Какие отделения самые затратные?»

Рейтинг поставщиков

Рейтинговая таблица всех поставщиков, отсортированная по общим расходам (наибольшие -- первыми). Нажмите на любой заголовок столбца для пересортировки. Каждая строка поставщика содержит:

Столбец Описание
Ранг (#) Позиция в текущем порядке сортировки
Название поставщика Наименование организации-поставщика
Количество поставок Количество поставок за период
Общие расходы Общая сумма закупок у данного поставщика (в GEL)
Ассортимент Количество уникальных позиций от поставщика -- большой ассортимент означает, что поставщик охватывает множество категорий

Нажмите на строку поставщика для раскрытия и просмотра его недавних поставок -- вложенная таблица с датой, количеством позиций и общей суммой каждой недавней поставки.

Журнал дефицита

Хронологическая запись каждого случая, когда остаток позиции достиг нуля. Этот раздел включает:

  • Наименование / Код позиции -- какая позиция закончилась
  • Отделение -- где произошел дефицит. Используйте фильтр отделений для фокуса на конкретном отделении
  • Дата обнуления -- когда запас достиг нуля
  • Дата пополнения -- когда запас был восстановлен (или прочерк, если ещё не пополнен)
  • Длительность -- как долго длился дефицит. Для текущих дефицитов вместо длительности отображается пульсирующий красный индикатор «Продолжается»

Используйте кнопку переключения сортировки для переключения между сортировкой по дате (сначала самые последние) и по длительности (сначала самые продолжительные).

Рейтинг отделений по расходам

Отделения, ранжированные по общим расходам на расходные материалы, с пропорциональными полосами (отделение с наибольшими расходами заполняет полосу полностью). Каждая строка отделения показывает общую стоимость, количество позиций и уровень исполнения. Нажмите для раскрытия и просмотра топ-позиций отделения с разбивкой по стоимости и процентом от общих расходов отделения.

Анализ списаний

Визуальная разбивка потерь по причинам, включающая три компонента:

  • Кольцевая диаграмма -- круговая диаграмма, показывающая долю списаний по причинам (Истекший срок, Повреждение, Хищение, Корректировка, Прочее). В центре отображается общая сумма потерь
  • Легенда -- кликабельные строки с перечислением каждой причины, её количеством, суммой и процентом от общих списаний. Нажмите на причину для детализации
  • Помесячные столбцы тренда -- сгруппированная столбчатая диаграмма, показывающая суммы списаний по месяцам с цветовой кодировкой по причинам. Показывает, растут или снижаются потери со временем
  • Детализирующая таблица -- при выборе причины из легенды появляется таблица со всеми отдельными списаниями: код, наименование, количество, сумма, дата и отделение

1.9 Клиника

Вкладка «Клиника» связывает складские операции с медицинской помощью. Она привязывает потребление расходных материалов к клиническим данным -- диагнозам, госпитализациям и номерам партий -- обеспечивая анализ затрат и отслеживаемость отзывов, которые невозможны по одним только складским записям.

Эта вкладка содержит три подвкладки:

Анализ затрат по диагнозам

Показывает расходы на расходные материалы, сгруппированные по коду диагноза ICD-10. Для каждого диагноза отображаются общие расходы на расходные материалы, количество случаев и средняя стоимость на случай. Отвечает на вопрос: «Какие диагнозы потребляют больше всего расходных материалов?»

Ключевые особенности:

  • Обнаружение выбросов -- диагнозы, общие расходы которых превышают среднее + 2 стандартных отклонения, отмечаются красным индикатором «Выброс». Используется статистическое обнаружение (среднее + 2 сигма) для выявления диагнозов с необычно высокими расходами на материалы
  • Разворачиваемые строки -- нажмите стрелку у любого диагноза для отображения основных позиций: конкретных расходных материалов, формирующих затраты, с количеством и стоимостью по каждой позиции
  • Подсветка строк-выбросов -- строки, отмеченные как выбросы, получают визуальную подсветку для привлечения внимания
Столбец Описание
Код диагноза Код ICD-10 с отображаемым названием ниже
Количество случаев Сколько госпитализаций связано с этим диагнозом
Общая стоимость Совокупные расходы на материалы по всем случаям с данным диагнозом
Средняя стоимость / случай Средние расходы на материалы на случай -- полезно для бюджетирования по типу случая

Отчет по затратам на госпитализацию

Показывает расходы на материалы по каждой госпитализации (пребыванию в стационаре), отсортированные по общей стоимости. Выявляет, какие конкретные случаи потребовали наибольшего количества расходных материалов.

  • ФИО пациента и Отделение -- идентификация случая
  • Длительность (дней) -- продолжительность пребывания
  • Общая стоимость -- все расходные материалы, использованные в течение госпитализации
  • Индикатор «Выброс» -- статистическое обнаружение выбросов отмечает случаи с необычно высокими расходами
  • Разворачиваемая детализация -- нажмите для просмотра каждого использованного расходного материала: наименование, количество, стоимость и дата

Отзыв партии

Инструмент отслеживаемости для отслеживания конкретного номера партии по всей больнице. Это критически важно для отзывов: когда производитель отзывает партию, необходимо точно знать, куда она попала и какие пациенты её получили.

Как использовать:

  1. Введите номер партии в поле поиска
  2. Нажмите «Поиск» (или нажмите Enter)
  3. Система возвращает карточку результатов, показывающую:
    • Данные позиции -- название и код продукта, связанного с этой партией
    • Общее количество затронутых пациентов (отображается красным индикатором)
    • Таблица разбивки по отделениям -- для каждого отделения, получившего эту партию: полученное количество, оставшееся количество, количество выданное пациентам и наличие оставшегося запаса
    • Рекомендация по карантину -- отделения, всё ещё хранящие эту партию, помечены желтым индикатором «Рекомендуется карантин»
    • Таблица затронутых пациентов -- перечисляет каждого пациента, получившего товары из этой партии: ФИО, отделение, количество и дата
Критически важная функция безопасности: Инструмент отзыва партии необходим для соблюдения нормативных требований. Когда производитель издает отзыв, этот инструмент предоставляет полную цепочку владения: от приемки на складе, через распределение по отделениям, до выдачи конкретным пациентам. Отделения с оставшимся запасом должны немедленно поместить затронутые товары на карантин.

1.10 Планирование

Вкладка «Планирование» предоставляет инструменты перспективного управления цепочкой поставок: отслеживание бюджета, автоматические триггеры дозаказа и прогнозирование спроса. Содержит три подвкладки.

Бюджет vs Факт

Сравнение запланированного бюджета с фактическими расходами по отделениям. Это центр финансового контроля расходов на расходные материалы.

Таблица отклонений показывает для каждого отделения: бюджет, фактические расходы, сумму отклонения и процент отклонения. Цветовая кодировка немедленно выделяет ситуацию:

  • Красный текст + индикатор «Перерасход» -- отделение потратило больше выделенного бюджета. Отклонение показывает сумму превышения
  • Зеленый текст + индикатор «В рамках бюджета» -- отделение укладывается в бюджет. Отклонение показывает оставшуюся сумму

Для установки или обновления бюджета отделения нажмите кнопку «Установить бюджет», чтобы открыть модальное окно, где вы выбираете:

  • Отделение -- из выпадающего списка с поиском
  • Месяц -- выберите целевой месяц с помощью селектора (по умолчанию -- текущий месяц)
  • Сумма бюджета -- введите сумму в GEL

Точки дозаказа

Статистически рассчитанный список позиций с оптимальными триггерами дозаказа. Система анализирует исторические модели потребления для рекомендации, когда и сколько заказывать.

Когда позиции опускаются ниже порога дозаказа, вверху отображается баннер оповещения с количеством позиций, требующих дозаказа.

Столбец Описание
Наименование / Код Идентификация позиции
Страховой запас Минимальное количество для хранения в качестве буфера против всплесков спроса
Точка дозаказа Когда запас падает до этого уровня, размещайте новый заказ. Рассчитывается на основе времени доставки и среднего потребления
Рекомендуемое кол-во заказа Рекомендуемое количество для заказа на основе расчетов оптимального размера заказа
Текущий запас Сколько сейчас в наличии
Требует дозаказа Красный индикатор «Требует дозаказа», если текущий запас на уровне или ниже точки дозаказа, иначе зеленый «ОК»
Достоверность Насколько надежен расчет: Высокая (зеленый, 90+ дней данных), Средняя (желтый, 30-90 дней), Низкая (красный, менее 30 дней истории)

Прогноз спроса

Прогностическое представление, показывающее ожидаемое потребление для каждой позиции на ближайшие 30, 60 и 90 дней. Представьте его как ответ системы на вопрос: «Исходя из текущего темпа использования, сколько нам потребуется в следующем месяце?»

Столбец Описание
Наименование / Код Идентификация позиции, а также количество месяцев доступных исторических данных
История (спарклайн) Миниатюрная столбчатая диаграмма, показывающая помесячную историю потребления. Каждый столбец представляет один месяц, высота пропорциональна потребленному количеству. Дает визуальное представление о тренде потребления
30д / 60д / 90д Прогнозируемое количество для каждого горизонта планирования
Доверительный интервал Статистический диапазон (нижняя оценка -- верхняя оценка) для 90-дневного прогноза. Узкий диапазон означает высокую достоверность
Тренд Индикатор со стрелкой направления: «Рост» (желтый, потребление увеличивается), «Стабильно» (зеленый, без изменений) или «Снижение» (синий, потребление уменьшается)
Точность прогноза: Прогнозы наиболее надежны для позиций с длительной историей потребления и стабильным спросом (позиции X-класса в ABC/XYZ). Для волатильных позиций (Z-класс) обращайте больше внимания на доверительный интервал, чем на точечную оценку. Позиции с историей менее 6 месяцев могут не отображаться в прогнозе.

1.11 Маппинг FHIR-ресурсов

Для команды интеграции: система аналитики получает данные из нескольких FHIR-ресурсов. Понимание этих маппингов полезно при создании пользовательских отчетов, устранении расхождений данных или интеграции с внешними аналитическими инструментами.

Функция аналитики FHIR-ресурс Используемые ключевые поля
Текущие остатки / KPI Basic (StockQuant) Extensions: sq-item-code, sq-location-id, sq-quantity, sq-unit-cost, sq-expiry-date, sq-lot-number
История движений SupplyDelivery type (receipt/transfer/writeoff), quantity, suppliedItem, occurrenceDateTime, supplier
Заказы / Уровень исполнения SupplyRequest status, quantity, authoredOn, requester, deliverFrom, deliverTo
Каталог позиций / ABC/XYZ DeviceDefinition identifier, deviceName, classification (group code), extensions for attributes
Клинические затраты / Диагнозы Encounter + Condition Encounter.period, Encounter.location, Condition.code (ICD-10), linked SupplyDelivery resources
Отзыв партии / Отслеживаемость SupplyDelivery + Basic (StockQuant) SupplyDelivery lot extension, destination (Patient reference), StockQuant sq-lot-number
Бюджеты Basic (Budget) Custom resource with department reference, period (month), budget-amount extension
Отделения Location / Organization Location for ward assignments, Organization for stock tracking and department hierarchy
Примечание о производительности: Аналитические запросы используют индексированный поиск по FHIR-расширениям и кешируют результаты на 30 секунд. Межвкладочная инвалидация кеша через BroadcastChannel обеспечивает, что при обновлении данных в одной вкладке браузера (например, проведении приемки) другие открытые вкладки отразят изменения в пределах TTL кеша. Базовый URL FHIR -- http://medimind.ge/fhir, все денежные значения используют валюту GEL (грузинский лари).
