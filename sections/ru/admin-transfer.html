11 Transfer System

11.1 Overview

The Transfer System manages inter-departmental inventory movements within the MediMind EMR Administration module. All transfer data is stored as FHIR SupplyDelivery resources with type='transfer'.

The module consists of 4 pages that cover the complete transfer lifecycle:

TransferCreatePage

Create new inter-department transfers using waybill or book-style interfaces

TransferConfirmationPage

Approval queue for pending transfers awaiting department confirmation

TransferPage

Browse, filter, edit, and delete completed transfers

TransferGroupPage

Aggregated view grouped by departments and date with CSV export

Transfer Status Lifecycle:
  • in-progress - Transfer created, awaiting confirmation from receiving department
  • completed - Transfer confirmed and inventory updated in both departments
  • abandoned - Transfer rejected or cancelled before confirmation

11.2 TransferCreatePage

The TransferCreatePage is the entry point for creating new inter-department transfers. It provides two distinct modal interfaces for different workflows and displays a table of recent transfers.

TransferWaybillModal
Standard waybill form with header fields, item search, and line item management. Best for structured entry.
TransferBookModal
Dual-panel book-style interface. Click items to move between available and selected panels. Best for quick selection.

Below the action buttons, a table displays the most recent 20 transfers with status indicators. Completed transfers are highlighted with a green background for quick visual identification.

11.3 TransferWaybillModal

The TransferWaybillModal provides a standard waybill form for creating transfers with precise control over each field.

Header Fields

Field Component Description
Date DatePicker Transfer date, defaults to current date
Document Number Auto-generated Format: DD/MM/YY-NNN (e.g., 06/02/26-001)
From Department Select Source department (sender)
To Department Select Destination department (receiver)

Item Entry

Field Component Behavior

Items Table

Added items appear in a line items table with the following columns:

Column Description Editable
Item Code Unique inventory item code No
Item Name Full name of the inventory item No
Unit Unit of measure No
Quantity Transfer quantity Yes (inline editing)
Price Unit price (4 decimal places) No
Total Calculated: quantity x price No (auto-calculated)

Footer Fields

Field Component Description
Direct Write-Off Checkbox When checked, skips confirmation step and creates transfer as completed immediately
Department Password PasswordInput Required. Validates authority to transfer from the source department.
Stock Validation:
  • Quantity cannot exceed current stock in the source department
  • Inline error messages appear if quantity exceeds available stock
  • Stock levels are checked in real-time when selecting items
  • If stock changes between selection and submission, the system re-validates

11.4 TransferBookModal

The TransferBookModal provides a dual-panel book-style interface designed for fast, visual item selection.

Left Panel: Available Items
Displays all items from the source department inventory. Includes a text filter to narrow results. Click any item to move it to the selected panel.
Right Panel: Selected Items
Shows items selected for transfer with inline quantity editing. Quantity fields have a yellow background (#FAFAAC) for visibility. Click to remove items.
  • Click to Move - Click an item in the left panel to add it to the right panel; click in the right panel to remove it
  • Inline Quantity Editing - Adjust quantities directly in the selected items panel
  • Yellow Highlight - Quantity input fields use background color #FAFAAC for clear visual distinction
  • Totals Summary - Footer displays sum of all line item totals
  • Filter - Text filter on the left panel narrows the available items list

11.5 TransferConfirmationPage

The TransferConfirmationPage displays an approval queue of pending transfers (status = in-progress) awaiting confirmation from the receiving department.

Confirmation Filters

Filter Type Description
Date From DatePicker Start of date range for filtering transfers
Date To DatePicker End of date range for filtering transfers
Document Number TextInput Search by document number (partial match)
From Department Select Filter by source department
To Department Select Filter by destination department

The table displays all transfers with status=in-progress. Clicking a transfer row opens the Confirmation Modal.

Confirmation Modal

Confirmation Process:
  • The confirmation modal allows editing the From Department and To Department before finalizing
  • On confirmation, the transfer status changes from in-progress to completed
  • Inventory is updated in both departments: source stock decreases, destination stock increases
  • Rejected transfers are marked as abandoned

11.6 TransferPage

The TransferPage displays a searchable, filterable list of all completed transfers with options to edit and delete records.

Filter Fields

Filter Type Description
dateFrom DatePicker Start date for the filter range
dateTo DatePicker End date for the filter range
fromDept Select Source department filter
toDept Select Destination department filter
goodsSearch TextInput Search by item name or item code
generalSearch TextInput General search across all fields (document number, department names, etc.)

Edit Modal

Clicking an existing transfer opens the edit modal with the following editable fields:

  • fromDeptId - Change the source department
  • toDeptId - Change the destination department
  • quantity - Adjust the transferred quantity
  • price - Update the unit price

Deleting a transfer requires a confirmation dialog before the record is permanently removed.

11.7 TransferGroupPage

The TransferGroupPage provides an aggregated view of transfers, grouping related records together for summary reporting.

Feature Description
Grouping Key Groups by: fromDeptId + toDeptId + date
Quantity Aggregate sum(quantity) across all transfers in the group
Total Aggregate sum(total) across all line items in the group
CSV Export Export grouped data to CSV with UTF-8 BOM encoding for proper character display
CSV Export Details:
  • Exported files include a UTF-8 BOM (\uFEFF) prefix for proper display of Georgian and Russian characters in Excel
  • Columns include: Date, From Department, To Department, Total Quantity, Total Amount
  • File name format: transfers-group-YYYY-MM-DD.csv

11.8 FHIR Resource Mapping

Each transfer line item is stored as a FHIR SupplyDelivery resource with type='transfer'. The resource uses custom extensions to store transfer-specific data.

Extension Type Description
SOURCE_DEPARTMENT Reference ID of the source (sending) department
SOURCE_DEPARTMENT_NAME String Display name of the source department
DEST_DEPARTMENT Reference ID of the destination (receiving) department
DEST_DEPARTMENT_NAME String Display name of the destination department
ITEM_NAME String Name of the inventory item being transferred
ITEM_CODE String Unique code identifying the inventory item
UNIT_OF_MEASURE String Unit of measurement (e.g., pcs, kg, ml)
UNIT_PRICE Decimal Price per unit (up to 4 decimal places)
LINE_TOTAL Decimal Calculated total: quantity x unit price 
SupplyDelivery (type='transfer')
├── status: in-progress | completed | abandoned
├── occurrenceDateTime: transfer date
├── identifier: DD/MM/YY-NNN document number
├── suppliedItem.quantity: transfer quantity
└── extension[]
    ├── SOURCE_DEPARTMENT / SOURCE_DEPARTMENT_NAME
    ├── DEST_DEPARTMENT / DEST_DEPARTMENT_NAME
    ├── ITEM_NAME / ITEM_CODE
    ├── UNIT_OF_MEASURE
    ├── UNIT_PRICE
    └── LINE_TOTAL

Document Number Format: DD/MM/YY-NNN where DD is day, MM is month, YY is two-digit year, and NNN is a sequential counter. Example: 06/02/26-001.

11.9 Direct Write-Off

Direct Write-Off Mode:

When the Direct Write-Off checkbox is enabled in the TransferWaybillModal, transfers are created with status='completed' immediately, bypassing the confirmation step entirely.

  • Inventory impact is immediate - Source department stock decreases and destination department stock increases at the moment of creation
  • The transfer will not appear in the TransferConfirmationPage approval queue
  • Use this option only when the receiving department does not need to verify the transfer
  • This action cannot be undone through the confirmation workflow; manual editing on TransferPage is required for corrections

11.10 Troubleshooting

Issue Cause Solution
Quantity exceeds stock Requested quantity is higher than available inventory in source department Reduce quantity or check current stock levels in the source department
Transfer not appearing in confirmation queue Transfer was created with Direct Write-Off enabled Check TransferPage for completed transfers instead; direct write-offs skip the confirmation step
Invalid department password Incorrect password entered for the source department Verify the department password with an administrator
Item not found in search No matching inventory items in the selected source department Verify the source department is correctly selected and has stock for the desired item
Duplicate document number Sequential counter collision on the same date The system auto-increments the NNN counter; retry the operation
CSV export shows garbled characters Spreadsheet application not detecting UTF-8 encoding The export includes a UTF-8 BOM; open in Excel using "Data > From Text/CSV" with UTF-8 encoding
Cannot edit completed transfer Transfer has already been confirmed and inventory updated Use the edit modal on TransferPage to adjust fields; note that inventory adjustments may be needed
Confirmation modal not loading Network error or session timeout Refresh the page and try again; check internet connection
